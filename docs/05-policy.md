# 05 中国大陆政策导航

政策核查日期：2026-10-12。以下为检索到的国家层面文件要点，不是对个人资格的核定。对象主要为职工养老保险参保者；城乡居民养老保险、特殊工种等不能直接套用。本章不自动推算个人退休日期。

## 三件事分开查

停止工作是劳动与生活安排；达到法定退休条件是制度判断；能领多少养老金是待遇计算。自己存够钱，不会自动改变后两者。

2024年全国人大常委会决定自2025年起实施渐进式延迟退休，用十五年逐步把男职工原60岁调整至63岁，原50岁和55岁退休的女职工分别调整至55岁和58岁。具体月份、身份与特殊情况需要查适用规则，不能对所有人直接说“现在都是63岁”。[S1](SOURCES.md)

职工按月领取基本养老金的最低缴费年限从2030年起，由15年逐年增加6个月，至2039年达到20年。最低年限是资格门槛，不等于缴满以后待遇不再变化。[S2](SOURCES.md)

满足相应条件可以选择弹性提前退休，距法定年龄最多提前3年，且不能低于原有50岁、55岁或60岁年龄底线。提前选择要符合所选年份的最低缴费年限；弹性延迟则适用法定退休年龄对应年份的最低缴费年限。延迟退休需要与单位协商一致，不能简单理解为自己单方想延就延。[S3](SOURCES.md)

## 养老与医保是两本账

国家医保局说明，退休后享受职工医保待遇涉及最低缴费年限；办理需符合当地规定。[S4](SOURCES.md) 不要拿养老的15年或20年直接当作医保年限。

离职前，向参保地经办机构核实：可选择的参保身份、缴费基数和金额、待遇衔接日期、中断后的等待或恢复规则、异地就医手续。需要跨城市退休的，还要确认养老待遇领取地和医保关系处理。把答复日期和办事页面留档。

## 个人养老金：优惠与限制一起看

现有公告规定个人养老金缴费在每年12000元限额内，可按规则在综合所得或经营所得中据实扣除；账户投资收益暂不征个税，领取时按3%单独计税。[S5](SOURCES.md)

抵扣不是退回12000元。实际税收效果取决于适用所得、税率与缴费前后的税额变化。还应比较产品费用、风险、可用性和资金锁定成本，不能只凭“省税”作决定。

2025年9月起实施的领取通知，除达到领取基本养老金年龄、完全丧失劳动能力、出国境定居等情形外，还规定了符合具体条件的医疗支出、失业保险金领取和低保情形。[S7](SOURCES.md) 这不等于普通辞职即可自由取出；不在此压缩复述复杂门槛，办理时查通知全文。

## 你需要拿到的六个答案

- 我属于哪一类参保和退休身份？适用哪个出生年月对照？
- 我的养老累计年限与医保累计、实际年限分别是多少？
- 如果停止全职工作，接下来如何参保，费用是多少？
- 哪个地方负责待遇领取与医保退休确认？
- 当前养老金估算基于什么工资、年限和未来假设？
- 哪些账户现在不能用，将来何时、税后多少可用？

工具中的养老金年龄和金额由用户手工输入，**不会审查政策资格**。不确定时，先用“暂不计入养老金”的保守情景；也保留合理估计情景，避免把不确定性误写成确定的零。
