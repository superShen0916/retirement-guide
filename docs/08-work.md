# 08 工作与再就业

工作除了收入，还可能提供结构、关系、认可和学习机会。退出一份工作时，要知道自己想减少哪部分，又希望保留哪部分。

## 先辨认消耗来自哪里

连续几周记录：真正疲惫的是通勤、工时、随时在线、管理关系、任务本身，还是缺少自主权？如果主要痛点是夜间响应，换一个岗位可能比完全退出劳动更合适；如果任何有考核的安排都让你无法恢复，一段休息可能更有价值。

这不是诊断工具。持续影响日常功能的身心问题，应寻求合适支持，不能要求自己单靠财务规划解决。

## 为技能保留可迁移的证据

对知识工作者，记录你解决过什么问题、怎样验证结果、哪些经验可以跨公司复用。公开作品要遵守保密与知识产权义务，不把公司代码、数据和内部文档上传出来。

AI等技术变化可能改变岗位要求，但不要把“必然永久失业”或“任何时候都能找回原薪资”当作唯一预测。更有用的是每隔一段时间真实查看岗位、与同行交流、做一次能力验证。

## 兼职收入先小规模验证

“以后做咨询每月赚5000元”是一个假设。至少检查：谁会付钱、获客花多少时间、收入有没有季节性、扣成本和税后还剩多少。没有实际客户时，在基准模型里谨慎处理，并一定做零收入情景。

所谓被动收入也可能有劳动：出租需要维护，内容产品需要更新，小生意有客服和获客。记录实际工时，计算自己是否愿意长期这样生活。

## 离职前的一页清单

确认财务缓冲、保障衔接、合同义务、已归属权益、归还设备和个人资料交接。确定休息预算与重新求职的触发条件。保留职业联系，但不把休息期变成每天追踪行业变化的另一份全职工作。

求职能力是备选，不是保险合同。行业低谷时再就业可能耗时更久，因此不能用一句“没钱再去上班”填平所有模型缺口。

**本章产出：**写清“我希望减少的工作特征”和“我希望保留的工作价值”，分别不超过三条。
