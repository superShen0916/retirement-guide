# 三分钟上手，再用一个晚上做第一轮规划

先得到一个你能解释的数字，再决定要查什么、试什么。第一次使用不需要安装 Python，也不必先决定退休年龄。

## 三分钟：算清短期停工缓冲

[打开在线计算器](https://retirement-before.supershen666.chatgpt.site)，或打开网页交付包里的 `index.html`。如果还没有自己的数字，先用页面的示例体验；之后再填下面几项：

| 要填的数 | 怎么理解 | 容易漏掉什么 |
|---|---|---|
| 可动用现金 | 现在就能用于生活的资金 | 自住房、不可取账户、尚未到账的收入不算现金 |
| 预留大额支出 | 从现金中先扣出的专款 | 搬家、必要维修、已经确定的家庭支出；不要再重复算进月支出 |
| 每月生活费 | 日常生活需要支付的费用 | 房租或房贷、全年不定期账单折月、家庭责任 |
| 额外保障缴费 | 尚未计入生活费的月支出 | 同一笔费用不能在生活费和这里各算一次 |
| 情景收入 | 这个情景里实际能收到的月收入 | 不把尚未验证的兼职当成必然；至少比较一次零收入版本 |

从场景案例照填时，现金填扣预留前的总额，已知大额预留和一次性启动费合并只扣一次。如果场景的月总支出已含保障，可以拆开填，或全部填入日常开销并将额外保障填 0。

这个数字回答的是：**固定收支下，现有现金能覆盖多久？** 它不包含投资收益预测，也不能回答终身退休是否可行。接近耗尽前就要采取行动，给找工作、搬家或调整安排留出时间。

先比较两个真实选择。例如“休息三个月”和“六个月没有工资”；不要为了让结果好看而填一个尚未拿到的收入。收入能完全覆盖支出时，也只是在这段收入有效期间、固定收支假设下不消耗现金，不代表终身安全。

接着只写三句话：

1. 我现在最想改变的是：____。
2. 我愿意先尝试的可逆版本是：____。
3. 出现____时，我会提前调整，而不是等现金用尽。

不知道下一步读什么？从 [六个场景](../README.md#六个场景把一个决定讲完整) 里挑一个，或先看 [休息三个月要准备什么](scenarios/rest.md)。也可先在[决策资料库](LIBRARY.md)查一个问题，或打开[退休现金流实验台](https://retirement-before.supershen666.chatgpt.site/lifetime.html)比较长期路径。

## 一个晚上：得到两条可比较的路径

这一轮的目标是：一份基本可信的账本、两个候选方案、一张待核实清单。材料不全也可以开始，把未知项写出来。

### 1. 先写目标，十分钟

完成这句话：“我希望在____之前，把____降下来，同时保留____。”例如减少随时在线的工作负担，保留基本收入与每周三次活动的时间。

先选择一个可逆版本：请假、减少额外项目、换岗、短期休息或半退休。也写一件不必等退休就能开始的事。

### 2. 准备四组数，三十分钟

| 数据 | 去哪里找 | 暂时不确定怎么处理 |
|---|---|---|
| 可支取资产 | 自己的账户记录 | 受限资金和未兑现权益另列 |
| 过去十二个月支出 | 支付记录与共同账单 | 列估算区间，不填虚假的精确值 |
| 未来阶段责任 | 与家人商量 | 生育、换房、照护等保留不同版本 |
| 税后收入时间段 | 合同、已发生收入、待遇估算 | 兼职与养老金分别做低估或零收入情景 |

填写 [财务盘点](../templates/financial-inventory.md)。第一版漏项很正常；先找出漏项，不靠提高预期收益率把缺口盖过去。养老金预计到账之前，需要单独安排可动用资金。

### 3. 把两个方案放在一张表上，二十分钟

使用 [个人计划](../templates/personal-plan.md)，至少比较下面四件事：

| 比较什么 | 方案 A | 方案 B |
|---|---|---|
| 想改变的工作负担 | | |
| 每月收支与现金缓冲 | | |
| 保障、家庭与再就业的待核实项 | | |
| 进入条件、复盘时间与回退办法 | | |

如果想比较跨年龄的长期现金流，再用本页下面的 Python 工具。只想评估短期休息，可以先留在网页计算器，不必完成开发环境安装。

### 4. 给计划加一次坏消息，二十分钟

先只改一个变量：把兼职收入改成零，增加一笔真实可能发生的支出，或把重新就业的时间延后。观察哪个变量最影响选择，再构造一个值得防范的组合情景。

把“我会怎么办”写进 [压力复盘](../templates/stress-review.md)。现金以外，也检查保障衔接、家庭安排、生活作息和求职渠道。

### 5. 得到行动，十分钟

| 结果 | 下一步 |
|---|---|
| 基准就有缺口 | 重新检查预算、退出时间与收入来源 |
| 基准可以、压力情景不行 | 明确能调整的支出和备用收入 |
| 各情景都能覆盖 | 核实保障与家庭安排，再做生活试运行 |
| 关键输入未知 | 优先查最影响结果的两项，暂缓追求精确年龄 |

本周可以同时做一件与退休金额无关的事：开始一个小愿望，约一次相处，或留一段真正不用完成任务的时间。

## 进阶：运行长期现金流工具

需要 Python 3.10+。在仓库目录运行；以下 Python 命令适用于 PowerShell、macOS 和 Linux，部分 Windows 安装需把 `python` 换成 `py`。

```bash
python tools/retirement.py examples/bridge.json --stress
```

这是从 45 岁开始的虚构示例。复制到已被 Git 忽略的 `private/` 目录，修改自己的版本，不要直接改公开案例。

PowerShell：

```powershell
New-Item -ItemType Directory -Path private -Force | Out-Null
Copy-Item -LiteralPath examples/bridge.json -Destination private/my-plan.json
python tools/retirement.py private/my-plan.json --stress
```

Bash（macOS / Linux）：

```bash
mkdir -p private
cp examples/bridge.json private/my-plan.json
python tools/retirement.py private/my-plan.json --stress
```

金额字段以“元”为单位，不能直接填“万元”的数值。全部金额使用起始购买力，收益率使用税费后的实际收益率。详细字段见 [工具说明](../tools/README.md)。

先看**首次未覆盖支出**，再看期末资产。早期有缺口、晚期恢复正资产，仍然有未解决的支出；没有缺口也只是某条假设路径成立。网页短期计算器按月分析固定收支，Python 工具按年分析跨阶段现金流，不能把两者的小数点结果直接当作同一种预测。

## 从源码打开网页（开发者）

普通读者使用网页交付包即可。需要从仓库源码重新生成网站时，在仓库目录执行：

```bash
python tools/build_site.py
```

然后双击 `dist/index.html`。`site/` 是网页源文件目录，GitHub 的源文件预览页不是在线计算器。网页构建过程和长期现金流工具分开：浏览器使用生成的网页时无需安装 Python。
