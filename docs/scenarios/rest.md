# 我想休息三个月，要准备多少钱？

你可能没有打算退休，只是希望有一段不用回复工作消息的时间。最难的常常不是批准自己休息，而是不知道：第三个月结束后，如果还没恢复、也没有找到新工作，怎么办？

把这次选择写成一段有预算、有检查点、可以延长或结束的休息。**休息三个月和三个月后一定重新拿到工资，是两个假设。**先给前者安排生活，再给后者留下余地。

## 先把三个日期分开

在纸上写下最后一笔正常工资到账日、计划重新找工作的日期、保守估计下一笔工资到账日。最后一个日期要考虑面试、入职和发薪间隔；不要直接用“休息结束”代替。

如果你想完整休息三个月，可以另留一段找工作和等待收入的窗口。窗口多长，用自己的行业、岗位和近期求职反馈判断。还没有线索，就先各算“再等一个月”和“再等三个月”，看差异能否接受。

## 一个虚构的六个月资金安排

以下是虚构人物小林的算术示例，全部金额为人民币元，不计收益、物价变化和任何尚未到账的收入。

小林有可及时支取的现金 90,000 元，其中 15,000 元已经留给一项不属于月度生活费的家庭支出；离职和休息启动另花 3,000 元。能够安排这段生活的资金是：

**90,000 − 15,000 − 3,000 = 72,000 元。**

| 月度项目 | 预算 | 怎么核实 |
| --- | ---: | --- |
| 住房及固定账单 | 2,500 | 查合同、近三个月缴费 |
| 吃饭和日常用品 | 2,000 | 从真实账单剔除工作报销 |
| 停工后新增保障缴费 | 800 | 只是示例，按个人核实结果替换 |
| 交通及其他必要开销 | 700 | 别把所有通勤节省都先花掉 |
| 兴趣、见朋友等可调支出 | 1,000 | 保留一个能正常生活的版本 |
| **合计** | **7,000** | 必要支出 6,000 元 |

| 情景 | 从 72,000 元中支出 | 窗口结束后剩余 |
| --- | ---: | ---: |
| 休息三个月 | 7,000 × 3 = 21,000 | 51,000 |
| 休息三个月，再等三个月收入 | 7,000 × 6 = 42,000 | 30,000 |
| 六个月每月都花到 8,500 元 | 8,500 × 6 = 51,000 | 21,000 |

15,000 元专款不在这些余额里，不能再把它当成可自由花的钱；它负责的那项家庭支出也没有重复放进月度预算。这个安排只检验一段短期现金流，不说明小林可以退休，更不保证半年后能就业。

## 给休息安排内容，也给它留白

不用把三个月排成自我提升训练营。可以每周固定一两次见人、适量的日常活动，以及一段完全没有产出要求的时间。先用 [一周生活设计](../../templates/week-design.md) 写一个普通星期，看看你期待的生活究竟是什么样。

如果准备长途旅行、进修或搬家，把费用单列为一次性项目。不要一面按低成本日常生活计算，一面默认休息期间可以随时增加旅行。也别把“以后接点活”算入已有资金，除非有明确的工作、成本和到账安排。

## 提前约好什么时候调整

比“没钱再去上班”更可执行的，是写下一张小卡片：

- 每月底核对一次余额和下一阶段已知支出，平时不用天天盯表。
- 到第八周，检查自己是想继续休息、尝试不同工作，还是开始求职。
- 如果未来三个月预计现金支出超过可安排资金，提前缩短休息、调整非必要项目或启动收入计划。
- 如果家人临时需要一笔钱，先重算窗口，再决定是否动用原来留出的专款。

触发条件由你决定。它的用途是让行动发生在仍有选择的时候，不是给休息设置绩效。

## 最容易漏掉的四件事

最后工资、报销和奖金应按实际到账时间处理；信用卡还款要和原消费对账，避免重复；原单位提供的某些支出支持可能不再存在；重新工作可能增加通勤、置装或过渡住宿费用。社保医保衔接单独查 [政策导航](../05-policy.md)，不要从别人的离职经验推定自己的情况。

**未来 48 小时：**导出最近三个月账单，列出未来半年已知大额；写出三个日期；分别算三个月和六个月零工资版本。然后再决定这次休息从什么时候开始，而不是先给自己定一个必须离职的日期。
