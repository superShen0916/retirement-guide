# 有房贷、孩子和父母要照顾，还能给自己留退路吗？

当家里有多个人依赖同一份工资，“我想休息一下”可能很快变成内疚。可是一味继续扛，也不等于家庭风险消失。可以先把问题缩小：如果收入下降三个月，谁的生活会改变，哪些付款必须继续，哪些责任可以一起重新安排？

**家庭退路需要一张共同账，也需要具体的人愿意承担具体的事。**“家里会支持”不能代替金额与时间，“我来多做家务”也不能默认覆盖原本的全部照护。

## 先把责任放进日历

不要把未来十年的所有支出都揉成一个平均数。先看未来十二个月：哪几月有集中缴费，贷款什么时候支付，父母有哪些已知安排，哪位家人在哪些时段无法照护。未决定的住房升级或教育选择，可以保留两套版本，不必为了一个整齐结果强行定下来。

| 责任 | 金额与付款时间 | 谁负责钱 | 谁负责时间 | 还缺什么信息 |
| --- | --- | --- | --- | --- |
| 住房还款与固定账单 | 按实际合同填 | 写姓名 | 处理维修的人 | 是否有额外年度费用 |
| 子女照护与教育 | 月费、学期费分开 | 写姓名 | 接送、陪伴的人 | 假期安排 |
| 父母支持 | 固定与不确定支出分开 | 写姓名 | 陪诊、探访的人 | 其他家人的可承担范围 |

表里不需要身份证号、账户密码或详细医疗记录。共同讨论可以使用摘要，原始敏感资料保存在私人位置。

## 一个虚构家庭的六个月过渡账

以下全部是虚构数字，不计收益和物价变化。小许一家可及时支取的现金 240,000 元，其中 40,000 元用于已经确定的一笔教育支出，20,000 元用于已经计划的父母相关一次性费用。这两项不放进后面的月表。另有本次换工作的一次性费用 5,000 元。

因此，可安排过渡资金为 **240,000 − 40,000 − 20,000 − 5,000 = 175,000 元**。

| 每月经常支出 | 金额 |
| --- | ---: |
| 房贷还款 | 5,000 |
| 日常生活、住房维护与交通 | 4,500 |
| 子女日常照护 | 1,500 |
| 父母固定支持 | 1,000 |
| 保障缴费及其他固定项目 | 1,500 |
| **合计** | **13,500** |

这张现金表把房贷按实际月供列支，**没有再从现金里扣掉整笔未还贷款本金**。房屋估值也没有加入可用资金。家庭净资产可以另外记录，但不能代替这六个月要付款的钱。

| 六个月收入情景 | 每月缺口 | 六个月需补足 | 剩余过渡资金 |
| --- | ---: | ---: | ---: |
| 小许暂时无收入，伴侣每月到账 9,000 | 4,500 | 27,000 | 148,000 |
| 小许每月到账 6,000，伴侣仍为 9,000 | 无缺口，每月结余 1,500 | 结余 9,000 | 184,000 |
| 两人六个月都无收入 | 13,500 | 81,000 | 94,000 |

第二行是假设整整六个月收入都按时到账；如果换岗第一月没有工资，要按月另列。第三行提醒这个家庭还要考虑收入同时受影响的可能。三行都不意味着能长期退休，也没有把伴侣未来收入当作个人可以无限使用的保证。

## 钱够之后，还要问谁更累

假设小许离开全职后，伴侣继续工作。双方要具体讨论：家务是否重新分配？照护带来的夜间中断由谁承担？小许找工作时谁接手？伴侣如果也想休息，有没有对等的机会？用一个普通工作周的时间表检查承诺，比一句“以后家里我管”更可靠。

家庭支持也可能有边界。父母愿意偶尔帮忙，不代表能长期全日照护；兄弟姐妹愿意分担，不代表付款和时间已经确定。可以逐项确认，不能只把最乐观的合作方式写进账本。

## 开一次不需要立刻辞职的家庭会议

先各自写出最担心的两件事，再共同选一个能撤回的三个月安排。约定必要支出、个人可自由使用的金额、照护分工，以及什么变化会触发重新讨论。可以用 [家庭会议模板](../../templates/family-meeting.md) 记录同意、不同意和待核实事项。

最容易遗漏的是集中缴费、维修、寒暑假照护、跨城探亲，以及家务重新分配后增加的服务费用。预留金若已承担某项费用，压力情景中只增加超出部分或另一件事，避免把同一风险算两遍。

**本周的行动：**各自导出家庭相关账单，完成十二个月付款日历；用收入正常、单人中断、两人中断三种情况计算未来三个月；安排一次会议，只决定下一段实验与复盘日。让责任被看见、被分担，才更可能给每个人留出一点余地。
