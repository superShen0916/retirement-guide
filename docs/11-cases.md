# 11 三个虚构案例

这些数据为教学构造，不对应任何真实个人。所有金额均为起始购买力，默认税费后实际收益2%，模拟到95岁期初；养老金金额与63岁起点均为人工假设，不代表资格认定或待遇承诺。自住房未进入可支取资产。

## A：有本金，仍需穿过桥接期

45岁起有300万元，每年支出12万元，63岁起假设养老金6万元/年。45至62岁这18个年度不能提前使用养老金。固定收益路径看似能走到终点，但初期下跌会明显改变结果。

配置：[bridge.json](../examples/bridge.json)。

## B：半退休收入不能无限外推

40岁起有180万元，每年支出9.6万元；每年6万元劳动收入只持续到50岁之前，63岁起假设养老金4.8万元/年。不能把十年的兼职机会当成终身年金。基准情景也出现缺口，应进一步比较延长收入、降低开销或推迟退出等选择。

配置：[part-time.json](../examples/part-time.json)。

## C：家庭责任与后期照护

50岁起有400万元，基础支出14.4万元/年；50至59岁额外家庭支持6万元/年；63岁起家庭假设养老金共9.6万元/年；65岁一次性改造30万元；80至94岁照护增加6万元/年。简化采用同一年龄轴，真实伴侣年龄差与各自待遇起点需要分开建收入段。

配置：[family.json](../examples/family.json)。

## 怎样使用案例

先替换自己的支出与阶段责任，再调整收益。不要因为一个案例本金接近自己，就照搬结论。这三个案例都没有计算出售住房、额外遗产、特定产品回报或再就业补救；如果有可核实依据，可以单独加入情景。

A与C的基准路径没有缺口，并不意味着“已获准退休”；压力路径都可能出现资金不足。B说明只看开始十年的状态，会忽略后期缺口。共同教训是看完整时间轴，并写下可执行的调整方式。
