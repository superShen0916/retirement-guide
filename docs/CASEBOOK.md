# 十二个虚构账本：相同存款，不同生活

下面是教学构造，不对应真实人物。所有金额为人民币元；固定月收支，不计收益和物价变化。预留先扣一次，兼职只持续指定月数。期末差额不能消除之前的现金缺口。

## 休息三个月，给下一份工资多留三个月

现金9万元，已知专款与启动费共1.8万元。把休息结束和下一次发薪分开。

| 项目 | 虚构输入 |
|---|---|
| 现金 / 一次性预留 | 90,000 / 18,000 |
| 每月生活 / 额外保障 | 6,200 / 800 |
| 每月收入 / 持续月数 | 0 / 0 |
| 对照期间 | 6 个月 |
| 期末现金差额 | 30,000 元 |

**这组数想说明什么：**只算三个月会漏掉求职与发薪窗口；这里用六个月检验缓冲，留下的钱仍需覆盖之后的生活。

| 项目 | 虚构输入 |

| 每月生活 / 额外保障 | 5,700 / 800 |

| 对照期间 | 3 个月 |
| 期末现金差额 | 6,500 元 |

**这组数想说明什么：**存款总额和可自由安排金额不是一回事；余额仍为正，也不代表适合把求职推迟到最后一个月。

## 同样30万元：一家人的账会完全不同

| 项目 | 虚构输入 |
|---|---|
| 现金 / 一次性预留 | 300,000 / 80,000 |
| 每月生活 / 额外保障 | 10,000 / 1,200 |
| 每月收入 / 持续月数 | 8,000 / 6 |
| 对照期间 | 12 个月 |
| 期末现金差额 | 133,600 元 |

**这组数想说明什么：**只把另一个人的工资当永久保障，会掩盖整个家庭对劳动收入的依赖。这里在第七个月将它归零。
