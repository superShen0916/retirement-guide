# 退休之前 · Retirement Guide

**为未来留余地，也给现在留生活。**

一份面向中国大陆普通劳动者的退休与生活自主指南。讨论攒多少钱，也讨论何时减速、如何保障、离开工作后做什么，以及哪些事情值得现在开始。

版本：v0.2.0 · 核查日期：2026-10-12 · 状态：完成第二轮校订，具备可复现构建与自动检查。

先读 [一个晚上的快速入门](docs/QUICKSTART.md)，或用 [几个可复算的选择题](docs/DECISIONS.md) 理解多工作一年、半退休和迁居的影响。

## 从这里开始

你不需要先决定要不要提前退休。先回答三个问题：

1. 如果半年没有工资，你的生活会发生什么？
2. 你想摆脱的是工作本身，还是某一种工作方式？
3. 如果退休时间推迟五年，哪些重要的事情仍然可以现在做？

本指南把“退休”拆成三个互不等价的状态：**离开全职工作、经济上不依赖工资、按政策领取养老金**。它们可能相隔很多年。

## 十分钟运行测算

需要 Python 3.10+，无第三方依赖。示例都是虚构数据，不包含发起者的私人资料。

```bash
python tools/retirement.py examples/bridge.json
python tools/retirement.py examples/bridge.json --stress
python tools/retirement.py examples/bridge.json --csv projection.csv
python tools/retirement.py examples/bridge.json --stress --json
python -m unittest discover -s tests -v
```

复制 JSON 示例，修改资产、支出和各阶段收入。金额单位统一为人民币元，**全部金额使用起始时点的购买力**，收益率输入税费后的实际收益率。工具输出年度现金流与首次缺口；它不预测市场、不提供成功概率，也不判断你“可以辞职”。详情见 [工具说明](tools/README.md)。

## 使用约定

- **事实**：政策与研究附来源及适用范围，见 [来源登记](docs/SOURCES.md)。检索到的文件不等于对所有后续修订做了穷尽核查；办理前仍需核实当地规则。
- **方法**：预算分类、实验和复盘是本仓库提供的思考工具。
- **假设**：收益率、未来养老金、寿命终点与案例数字均不是承诺。
- 这是一份教育性指南，不替代个人投资、税务或医疗方案。没有推荐具体金融产品，也不收集用户数据。
