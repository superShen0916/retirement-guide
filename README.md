## 先看一个会改变直觉的例子

45 岁，有 300 万元，每年花 12 万元，假设 63 岁起每年领 6 万元养老金，税费后实际收益设为 2%，模拟到 95 岁期初：

| 只改变收益路径 | 首次未覆盖支出 | 95 岁期初资产 |
|---|---|---|
| 每年固定 2% 实际收益 | 所设范围内无 | 约 42.89 万元 |
| 全部年份零实际收益 | 77 岁年度 | 0 元 |
| 前两年 −20%、−10%，随后回到原假设 | 70 岁年度 | 0 元 |

三条路径都来自[同一份虚构配置](examples/bridge.json)。未来养老金没有提前拿来付今天的账，早年的缺口也没有被后来的收入抹掉。

**[亲手改一个数，看看哪一段先变了 →](https://retirement-before.supershen666.chatgpt.site/lifetime.html)**

这里没有成功率或“可以辞职”的判决。收益、养老金和模拟终点均为输入假设；模型的价值在于暴露条件，帮助你知道下一步要核实什么。

## 同样 30 万元，过的可能是三种生活

以下为三个虚构的一年账本，不计投资回报与物价变化。预留只扣一次，未确认的收入不外推。

| 处境 | 一次性预留 | 每月生活与保障 | 情景收入 | 12 月末现金差额 |
|---|---:|---:|---|---:|
| 较低固定支出的独居生活 | 6 万 | 5,000 | 无 | 18 万 |
| 有家庭责任，另一份收入仅确认半年 | 8 万 | 11,200 | 8,000/月 × 6 个月 | 13.36 万 |
| 搬迁后增加探亲、交通和回迁预留 | 8.5 万 | 7,500 | 无 | 12.5 万 |

它们没有在给生活方式排名。表格让你看到：预留用途、收入期限和日常责任，会怎样改变同一笔存款能支持的选择。

还有：5 万元起步、降薪换岗、兼职接不到单、名下有房但现金紧、一个人先停工、两人同时休息，以及每月多花 3,000 元的对照。

## 数字和来源，怎样追溯

- **原创方法**：清楚写出假设、算式和边界，可自行修改与反算。
- **政策原文**：说明制度、对象和地区；发布日期、实施日、核查日分别记录。
- **研究解读**：说明来源支持什么；官方问答、摘要页和完整报告分别记录，未读取的全文不会写成已核查。
- **虚构案例**：只用于展示不同条件，不冒充真人故事、当地办理结果或市场预测。

新增资料核实了 16 个不同文件或官方机构页面：13 个可读取相关公开正文，3 个仅取得检索文字；其中包括官方转载和网页摘要，具体见[逐来源记录](docs/RESEARCH-NOTES.md)。原 S1–S7 的历史状态保留于[来源登记](docs/SOURCES.md)。

## 本地阅读、复算与参与

交付包解压后双击 index.html 可使用网页，阅读版.html 集中收录全部长文。使用源码时需要 Python 3.10+；运行网页模型测试另需 Node.js 22+，均无第三方运行依赖。

```bash
python tools/build_library.py
python tools/build_reader.py
python tools/build_site.py
python tools/retirement.py examples/bridge.json --stress
python -m unittest discover -s tests -v
node --test tests/test_runway.mjs tests/test_lifetime.mjs
```

字段与精确结算时点见[年度工具说明](tools/README.md)，发布流程见[维护说明](RELEASE.md)。欢迎补充可复算反例、带地区与原文的政策更正，以及获得授权的匿名经历；失败、回退和重新工作同样值得记录。[贡献指南](CONTRIBUTING.md)
