从数字到选择：几个可复算的小例子

本页全部是算术示例，不是收益预测或适用于所有人的建议。金额统一按当前购买力。

“再多上一年班”到底换来了什么

假设税后收入30万元，年度全部支出12万元，那么多工作一年新增储蓄18万元，未计投资波动。退出时间也推迟了一年，少了一年需要资产支持的支出；但不要再在同一年的财富增量里重复加上12万元，收入减支出的18万元已经计入了这一年的生活成本。

正确做法是把两个方案对齐到同一个未来年龄比较：方案A现在退出，方案B工作一年后退出。两者各自按年度算完整现金流。比较的不只是余额，还包括这一年的健康、家庭机会和职业价值。

月支出少1000元，有多大影响

全年少1.2万元。用“年开销÷3%”这种粗略筛选，目标本金相差40万元。但3%本身不是已验证的安全率，所以40万元只是某个假设下的敏感度，不是生活每降低一点就能确定少工作几年。

应先问这1000元来自哪里：低价值订阅、居住条件、见朋友的机会，还是一个很喜欢的兴趣？同样金额的削减，生活代价可能完全不同。

半退休收入能否缩短桥接期

假设兼职税后每年6万元、持续十年，总收入为60万元，未折现。它可以减少这十年对资产的支取，但十年后不再存在。不能用6万元除以3%，就把这份短期工作当成价值200万元的永久资产。

在模型中建立有限时间段，同时用零收入版本比较。关注为了赚这笔钱实际需要多少时间，以及收入减少时能否接受。

低成本城市是否一定更适合

假设租金每年少2.4万元，但搬家一次性花3万元，每年探亲交通多1万元，其余不变，则经常性净节省1.4万元，简单回收期约2.14年。这个计算没有包含医疗可达性、支持网络、职业机会和未来租金变化。

迁居可以先短住。只有开销真的下降、生活也能接受，才值得把节省写进长期基准。

要不要给后代保留本金

“95岁期初余额不为负”和“95岁时保留一笔遗产”是不同目标。当前工具会显示期末资产，你可以与自己设定的保留金额比较，但工具不会自动按目标遗产倒推所需本金。

保留本金可能带来安心，也可能限制自己想做的事情。先明确责任与意愿，再决定数字；不要把本金必须永远增长视为唯一正确答案。

净资产过百万，为什么仍可能撑不过两年？

现金与资产 · 原创方法

先看结论：先算下一笔账单能用的钱，再看包含住房的净资产。

房屋净值说明你拥有多少权益，不说明下个月能拿出多少钱。把自住房估值填进生活本金，同时继续享受免费居住，相当于把同一套房用两次。卖房还贷也会改变以后住在哪里、花多少钱；未完成交易前，估值不能替代现金。欠款总额与每月还款则属于不同维度，不能在生活费里付着月供，又一次性从现金减去全部本金。

现在能做的三件事

  1. 将资产分成今天可支取、需出售、暂不动用三栏，分别填净到账额与等待时间。
  2. 给未来一年已确定的大额付款单列预留，核对每月支出是否已经包含月供。
  3. 先用现金计算停工期限；若需要卖房，再另建包含还贷、交易支出和替代住房的方案。

具体情景 / 算例：虚构：房屋估值1,800,000元、未偿房贷900,000元、现金160,000元，净资产=1,800,000+160,000−900,000=1,060,000元。先预留40,000元，月支出6,000元已含月供，则静态日常缓冲=(160,000−40,000)÷6,000=20个月。假设不卖房、无收入、无收益及额外支出。

适用边界：这里的20个月只对应给定现金与收支；房屋估值、成交时间和未来居住方案变化，都需要重新算。

应急金留了六个月，为什么不能再算成六个月假期？

现金与资产 · 原创方法

先看结论：预留是对同一笔现金分配用途，不能同时支持两项计划。

同一张银行卡上的余额容易在不同表里重复出现：一会儿是生活本金，一会儿又是应急金。反过来，如果已从总额扣除应急金，再从日常缓冲扣六个月，也会把计划算得过紧。应急金可以在真实紧急情况下使用，但一旦被动用，原来的风险承受能力就改变了，不能把触底当作正常退出点。

现在能做的三件事

  1. 把当前现金完整分给已知支出、日常计划和应急三类，检查三类之和等于余额。
  2. 给应急账户写明允许使用的事件，以及一旦使用后需要缩短休息或恢复收入的动作。
  3. 每月只更新一次总表；转账不记成新增储蓄，也不把账户名字当成多出来的保障。

具体情景 / 算例：虚构：现金180,000元，已知支出预留30,000元，应急预留36,000元，则日常可用=180,000−30,000−36,000=114,000元。月消耗6,000元，日常缓冲=114,000÷6,000=19个月；若计划休息12个月，剩余日常预算=114,000−12×6,000=42,000元。应急36,000元没有再支持另一段六个月假期。假设零收入、零收益。

适用边界：应急金额与触发条件由家庭责任决定；19个月是日常预算耗尽点，不是建议休息到第19个月。

年平均够花，为什么第二个月就可能见底？

现金与资产 · 原创方法

先看结论：年缴账单既要折算月均，也要放回真实付款月份。

年度平均适合比较生活成本，却可能遮住付款时间。保险、维修、学费或年租即使只发生一次，也不会按你的月均表分十二次扣款。短期休息尤其要看下一次付款在哪个月，而非只看过去一年的平均数。已预留的钱也不能一面从起始现金扣掉，一面在到期月再作为额外消耗重复扣除；应选择一种一致的记账口径。

现在能做的三件事

  1. 从未来十二个月日历找出不按月支付的账单，填金额、最早付款日和可否推迟。
  2. 同时保留月均成本表和逐月现金表，用逐月表寻找首次不足的月份。
  3. 若单独圈存年缴款，在现金表标成预留转付款；若未圈存，就在付款月扣除一次。

具体情景 / 算例：虚构：可用现金20,000元，每月日常4,000元，第2个月末另付年缴款12,000元。月均法把年缴摊成12,000÷12=1,000元，算出20,000÷(4,000+1,000)=4个月。真实月末余额却是第1月16,000元，第2月20,000−2×4,000−12,000=0元，第3月缺4,000元。假设账单不可分期，无收入和收益。

适用边界：若年缴款可以合法延期、退款或分期，需用实际合同重排；过去的付款月份不保证下一年相同。

提取率算出一个本金数，为何还不能据此辞职？

现金与资产 · 原创方法

先看结论：提取率只能展示假设的敏感度，不能代替逐年收支与坏情景。

用年开销除以一个百分比，答案看起来像精确门槛，但分母只是你选的假设。相同支出换一个比例，本金会差几十万元；资产下降后，固定支出占剩余本金的比例还会升高。是否能长期支持生活，还涉及支出变化、年限和现金出现缺口的时间。后期余额恢复，也不能让早期已经付不起的账单自动消失。

现在能做的三件事

  1. 把选用比例写在结果旁，同时再算一个更高和一个更低的比例，观察差额。
  2. 另建资产先跌、收入中断和一次大额付款的版本，逐年检查是否需要卖出或借款。
  3. 为支出削减或恢复收入设触发点，避免把本金达到某数额当作唯一决策条件。

具体情景 / 算例：虚构筛选：年支出72,000元，按3%对应72,000÷0.03=2,400,000元，按4%对应1,800,000元，相差600,000元。再假设后者第一年先跌20%、年底支取72,000元，余额=1,800,000×0.8−72,000=1,368,000元；第二年同额支出占期初余额约5.26%。这只是人为压力路径，不是市场预测。

适用边界：3%、4%和下跌20%均为本例输入，不代表任何适用人群的安全率，也没有验证长期可持续性。

账户多了3%，为什么购买力可能只多不到1%？

现金与资产 · 原创方法

先看结论：长期算生活能力，应把税费后的余额换成同一时点购买力。

先忽略费用，再把名义增长直接当作每年可以多花的钱，会同时高估积累和可支付支出。用名义收益减通胀可作粗略心算，精确换算则应比较两个增长倍数。还要避免在使用实际收益率后，把已经按当前购买力填写的同一笔支出再次加通胀，造成另一种重复计算。

现在能做的三件事

  1. 先列所有税费及扣款的时点，用最终到账额计算名义净增长，不拿宣传数字直接入模。
  2. 选定当前购买力或未来名义金额的一种口径，并给全部收入与支出标记口径。
  3. 在长期表中用增长倍数相除换算实际变化；改变通胀假设时同步重算。

具体情景 / 算例：纯虚构算术：年初100,000元，假设全年毛增值4,000元，税费合计扣1,000元，年底103,000元，名义净增长3%。若同一篮子商品价格涨2%，原购买力需要102,000元维持；实际增长=1.03÷1.02−1≈0.9804%，年底按年初价格折算为103,000÷1.02≈100,980.39元。假设全年无存取款。

适用边界：本例不描述任何产品、税制或未来收益；若费用按不同基数或时点收取，须先按真实现金流重算。

降薪四分之一，真实时薪却可能提高？

工作与时间 · 原创方法

先看结论：把通勤与上班专属开销放进去，再给换回的时间定价。

月薪只反映到账金额，无法说明一份工作占用多少生活。通勤、固定加班和只能因工作购买的服务，都可能改变方案排序。也不能把所有外卖或衣服一概归到工作成本：换工作后仍会发生的部分不该当作节省。真实时薪更高也不等于家庭现金一定够用，它回答的是用多少时间换回多少钱，仍需另看每月缺口。

现在能做的三件事

  1. 记录连续四周的工作与通勤时间，把可自由支配的午休与必须在岗的等待区分开。
  2. 只扣换工作后确实能消失的交通、餐费差额等支出，使用同样的税后收入口径。
  3. 计算每月少拿多少钱、换回多少小时，再为其中两段时间安排具体用途，检验是否真的可用。

具体情景 / 算例：虚构：A月收入12,000元，工作176小时、通勤44小时，专属开销1,200元；B收入9,000元，工作144小时、通勤12小时，专属开销300元。A真实时薪=(12,000−1,200)÷220≈49.09元，B=8,700÷156≈55.77元。每月少2,100元，换回64小时，代价约32.81元/小时。其余支出相同。

适用边界：时间的连续性、岗位稳定性和福利差异未折成金额；照护责任占用的新空闲时间应单独注明。

多上班一年，是多攒储蓄还是还要再加一年生活费？

工作与时间 · 原创方法

先看结论：比较现在退出和一年后退出，必须把两条路算到同一个日期。

多工作一年的净储蓄已经扣了这一年的生活费，但与立即退出相比，对方同一年还要从资产支付生活费。容易算错的地方是切换比较口径：先拿净储蓄与当前余额比较，又额外把少支付的生活费加两遍。把两个方案各自的起点、收入、支出和终点全部列出来，差额自然出现。

现在能做的三件事

  1. 给两个方案选同一个终点，例如一年后的同一天，使用相同起始资产与价格口径。
  2. 分别填这一年全部收入、日常支出及仅因工作发生的成本，逐项计算期末余额。
  3. 把这一年失去或获得的家庭机会写在金额旁，再比较差额是否值得继续工作。

具体情景 / 算例：虚构：今天可用资产500,000元，两种方案未来一年都花80,000元。A现在退出，年底余额=500,000−80,000=420,000元；B再工作一年，税后收入180,000元，年底=500,000+180,000−80,000=600,000元。两方案差180,000元，即B新增储蓄100,000元加A消耗80,000元。不能再额外加一次80,000元得到260,000元。假设零收益。

适用边界：若工作方案支出更高、退出后有收入或投资路径不同，要分别入表；金额差不替代个人对这一年的评价。

先看结论：返岗触发金额应覆盖找工作过程、一次性成本和保底余额。

决定重返工作与第一笔工资到账之间并非同一个时点，个人计划需要写出等待期。把招聘、准备、入职和工资结算全部当成零耗时，会把账面缓冲误当成可自由休息的期限。培训或搬家费也可能先于收入发生。设置触发点，是为了在仍能承受等待时开始行动。

现在能做的三件事

  1. 自行调查候选岗位，把个人预估的准备期、求职期与到账等待期合并，另做更慢版本。
  2. 列求职需要先付的设备、交通或培训支出，不把尚未确定的补贴写成必得收入。
  3. 用保底现金加等待期支出再加启动费用设提醒；到点先启动求职，而非要求自己立即入职。

具体情景 / 算例：虚构：日常可用120,000元，月支出6,000元，希望开始领工资时仍留18,000元。假设启动求职至首薪需4个月，另需一次性12,000元，则触发余额=18,000+4×6,000+12,000=54,000元。零收入期间最多先休息(120,000−54,000)÷6,000=11个月；再花24,000元生活费及12,000元启动费后，剩18,000元。

适用边界：四个月是虚构个人估计，不是招聘市场保证；一旦进展落后，应提前调整支出、工作范围或休息期限。

兼职只确定六个月，为什么不能按每月缺口一直除？

工作与时间 · 原创方法

先看结论：有限期收入应逐段抵扣消耗，结束后恢复没有这笔收入的预算。

一份短合同能延长休息时间，却不会让每个月都永久少花同样的钱。直接拿现金除以当前缺口，相当于默认为兼职永不结束；把全部合同收入一次加进起始现金，又可能掩盖尚未到账时的付款困难。填写收入应先扣成本，不能把承诺流水当作可支配收入。

现在能做的三件事

  1. 给每笔收入填写开始月、最后到账月和扣除成本后的金额，不用一个平均数覆盖全程。
  2. 至少比较按合同收到、只收到一半和完全没收到三个版本，逐月检查现金是否足够。
  3. 在合同结束前设续约检查日；没有落实的新合同从基准表删除，再决定是否恢复其他收入。

具体情景 / 算例：虚构：起始现金120,000元，月支出8,000元，兼职净收入3,000元仅在前6个月月末到账。前6个月消耗=(8,000−3,000)×6=30,000元，剩90,000元；以后可支撑90,000÷8,000=11.25个月，总静态时长17.25个月。若一直按120,000÷5,000算成24个月，会多算6.75个月。假设无收益，无其他收入与额外支出。

适用边界：小数月是金额等价时长；账单不能按天分摊时，应看实际首次付款缺口，不能保证可完整生活到该日。

休息三个月，为什么可能需要准备八个月的支出？

先看结论：休息期限与没有工资的总期限，应分别做预算。

三个月休息结束，并不意味着第四个月工资自动回来。若休息后才开始找工作，求职和到账等待都继续消耗现金；若边休息边求职，又可能无法得到原先期待的完整休息。把这两种安排分别命名，才能同时讨论资金与体验。

现在能做的三件事

  1. 在日历标出停止领薪、完整休息、开始求职、预计入职与首薪到账，检查阶段有无重叠。
  2. 按从最后一笔工资到第一笔新工资的总间隔备钱，将求职启动费另列一次性付款。
  3. 给每个阶段设置检查日：若求职未启动或面试少于预期，缩短后续空窗并重排预算。

适用边界：阶段时长全是假设；若已有确定入职日或休息期间仍领薪，按实际净现金流替换，不能机械套用八个月。

房租每月便宜一千五，为什么住一年还可能亏钱？

住房与迁居 · 原创方法

先看结论：迁居先算净节省与回收期，再问自己会不会住那么久。

低租金是醒目的数字，但搬家、重新添置、探亲和维持原有关系也可能花钱。把一次性支出漏掉，会把刚搬过去的第一年写得过于便宜；把全部押金当永久损失，又会高估成本。回收期只回答需要住多久才能靠现金节省抵回前期投入，不证明当地生活适合自己。

现在能做的三件事

  1. 同时列搬家前后的月租、交通、探亲等经常性支出，只用二者差额计算净节省。
  2. 把搬运与不可回收添置列入前期投入，押金另列占用现金，避免混在一起。
  3. 计算计划居住期的累计差额，再做租金上涨、提前返回两个版本，先决定试住期限。

具体情景 / 算例：虚构：原租金4,000元/月，新租金2,500元/月，但探亲等新增500元/月，因此净节省=4,000−2,500−500=1,000元/月。搬家和不可回收添置一次花18,000元，简单回收期=18,000÷1,000=18个月；若只住12个月，累计差额=12×1,000−18,000=−6,000元。假设其他支出不变，押金全部退回，未计利息。

适用边界：回收期不包含支持网络、工作机会和生活体验；若每月净节省为零或负数，就不存在此式所说的回收期。

押金能退，为什么搬家时仍可能周转不过来？

住房与迁居 · 原创方法

先看结论：可退押金不是永久支出，但在退回之前不能拿来交下一笔账单。

净成本与现金最低点要分开看。旧押金还没到账，新房可能已要求先付押金与首期租金；把两笔押金直接相减，会漏掉同时占用的阶段。反过来，把新押金全部当生活成本，又会低估仍属于自己的资产。应先记录付款与退款时间，再判断现金最低点。

现在能做的三件事

  1. 分别写旧押金预计退款日、新押金付款日和各期租金日，依据自己的合同核实条件。
  2. 逐日或逐周计算搬家窗口的最低现金，旧押金未到账前不计入可支付余额。
  3. 给退款晚到或扣款另留空间；收到退款时记资产转回，避免把它误认成新增收入。

具体情景 / 算例：虚构：起初现金42,000元，旧押金另有8,000元。搬家新押金10,000元、搬运4,000元；月租3,000元、其他生活4,000元。第1月末现金=42,000−10,000−4,000−3,000−4,000=21,000元；第2月先付7,000元降至14,000元，再收到旧押金8,000元回到22,000元。两月后仍有新押金10,000元，资产共32,000元。假设足额退款且无收入。

适用边界：押金的可退性、扣款和到账时间取决于实际合同与执行情况；示例不认定任何租赁权利或退款保证。

基本养老金是两笔账相加，先拆开再谈够不够

保障与政策 · 政策原文

先看结论：基础养老金由社平工资、缴费指数和缴费年限决定；个人账户养老金是储存额除以计发月数。两块口径不同，不能只盯其中一个数字。

国发〔2005〕38号确立的计发办法里，基础养老金以当地上年度在岗职工月平均工资与本人指数化月平均缴费工资的平均值为基数，缴费每满一年发给1%；个人账户养老金为个人账户储存额除以计发月数。计发月数随退休年龄变化，退休越晚、计发月数越小，同一笔储存额摊出来的月数越少、每月金额越高：50岁为195、55岁为170、60岁为139、63岁为117、65岁为101。只比较账户余额，会漏掉缴费年限与退休年龄对基础养老金的长期影响；只比较社平工资，又会把个人账户的实际积累忽略掉。

现在能做的三件事

  1. 在参保地经办渠道打印个人权益记录，确认累计缴费年限、视同缴费年限和个人账户储存额三项数字。
  2. 用两个式子分别估算：基础养老金＝(计发基数＋本人指数化月平均缴费工资)÷2×缴费年限×1%；个人账户养老金＝储存额÷对应年龄的计发月数。
  3. 把退休年龄往后推一到三年重算一次，比较两块各自变化多少，而不是只看总额。

具体情景 / 算例：虚构：计发基数设为9,000元，本人平均缴费工资指数为1.0，缴费年限30年，个人账户储存额200,000元。60岁退休：基础养老金=(9,000+9,000)÷2×30×1%=2,700元，个人账户=200,000÷139≈1,438.8元，合计约4,138.8元。若改为63岁退休且缴费年限增至33年：基础养老金=(9,000+9,000)÷2×33×1%=2,970元，个人账户=200,000÷117≈1,709.4元，合计约4,679.4元。

适用边界：过渡性养老金、地方增发项目、记账利率与计发基数每年调整均未计入上例；各省细则与历年基数不同。这里只示范口径，不预测个人待遇。

保障与政策 · 政策原文

先看结论：从2025年起用十五年渐进延迟，男女职工节奏不同；2030年起最低缴费年限还要从15年逐步提到20年。

决定规定：男职工和原法定退休年龄为55周岁的女职工，法定退休年龄每四个月延迟一个月，分别逐步延迟至63周岁和58周岁；原法定退休年龄为50周岁的女职工，每二个月延迟一个月，逐步延迟至55周岁。同时，从2030年1月1日起，按月领取基本养老金的最低缴费年限由十五年逐步提高至二十年，每年提高六个月。这意味着两件事同时移动：你能办退休的月份，和你够不够年限。按同一年出生，男职工大约延迟一到几个月，接近改革完成时出生的人才会明显后移；只看新闻标题里“63岁”容易把自己吓到或误判。

现在能做的三件事

  1. 按出生年月和原法定退休年龄类别，查官方发布的延迟法定退休年龄对照表，记录查询日与结果。
  2. 同时查提高最低缴费年限情况表，确认自己退休当年对应的年限要求，而不是默认15年。
  3. 把两个结果写进自己的时间轴，再看停工计划要覆盖几个月没有养老金的桥接期。

具体情景 / 算例：虚构：按官方解读举例，男职工1965年1月至4月出生的，法定退休年龄提高1个月，即60周岁零1个月；1965年5月至8月出生的提高2个月；1976年9月至12月出生的为63周岁。缴费年限侧：按每年提高六个月推算，2030年为15年6个月，2031年为16年，此后逐年递增，至2039年达到20年。

适用边界：具体月份以官方对照表和个人参保记录为准；特殊工种、高海拔等另有规定者需另查。本文不认定个人退休资格，也不把推算的年份写成已公布的逐年的表。

弹性退休是一个区间，不是一个开关

保障与政策 · 政策原文

先看结论：达到最低缴费年限可以自愿提前，最多三年且不低于原法定退休年龄；延迟也最多三年，并需与单位协商一致。

弹性退休给了前后各最多三年的选择空间，但两端都有硬条件：提前退休要求已达到按月领取基本养老金的最低缴费年限，提前时间最长不超过三年，且不得低于原法定退休年龄；延迟退休要求所在单位与职工协商一致，延迟最长不超过三年，并明确不得违背职工意愿、不得违法强制或变相强制。程序上，自愿提前退休至少要在本人选择的退休时间前三个月以书面形式告知所在单位；弹性延迟退休需单位与职工提前一个月书面明确延迟时间等事项。把弹性当作“随时可退”，会在时间和材料上落空。

现在能做的三件事

  1. 先确认自己是否已达到当年适用的最低缴费年限，再看有没有提前的空间。
  2. 若准备提前，按至少提前三个月书面告知的要求排日程，保留告知与受理记录。
  3. 若希望延迟，先与单位就岗位、薪酬与社保缴纳达成书面一致，不要默认原岗位自动延续。

具体情景 / 算例：虚构：一个人达到最低缴费年限，原法定退休年龄为60周岁，其改革后的法定退休年龄为61周岁零8个月。他最多可提前到60周岁办理；若想继续工作，需在单位同意下最多延迟到64周岁零8个月。两个方向的最长距离都是三年，但起点不同。

适用边界：面向职工基本养老保险的一般规则；灵活就业人员、特殊工种及另有规定者办理方式不同。2024年底前已达到原退休年龄的人员不适用该弹性办法。

  1. 向父母户籍地经办渠道核实三个数字：当地当前基础养老金、可选缴费档次与对应补贴、年限养老金加发规则。

  3. 确认待遇资格认证周期与办理方式，避免因未认证暂停发放；同时核对补缴是否还能享受补贴。

个人养老金的税收优惠，先看自己适用哪一档税率

保障与政策 · 政策原文

先看结论：每年限额12,000元，缴费可扣除、投资收益暂不征税、领取时单独按3%计税；税率本就低的人，实惠有限而锁定期很长。

自2024年12月15日起，个人养老金制度在全国全面实施。税收处理分三段：缴费环节按12,000元/年的限额在综合所得或经营所得中据实扣除；投资环节计入账户的投资收益暂不征收个人所得税；领取环节不并入综合所得，单独按3%的税率计算缴纳个人所得税。优惠的大小取决于你缴款当年的边际税率：边际税率越高，当年抵扣越值钱；若本来就在3%这一档，缴时省下的与领取时缴出的大致相抵，换来的是一笔锁定到退休、提前支取受严格限制的资产。领取条件也在细化，除达到领取基本养老金年龄外，公开信息显示患重大疾病、领取失业保险金达到一定条件、正在领取最低生活保障金等情形也可申请领取。

现在能做的三件事

  1. 先估算自己当年适用的边际税率，再判断抵扣价值：税率越高，节税效果越明显。
  2. 把“节税金额”与“资金锁定到退休”放在一起权衡，不要只按最高档税率算收益。
  3. 记录缴费凭证与账户开立行，领取时的代扣代缴由账户所在市的商业银行办理，提前领取条件需另查最新规定。

具体情景 / 算例：虚构：年缴12,000元。若当年边际税率为20%，缴款环节少缴税约2,400元；领取时按3%计税，约360元，静态差额约2,040元。若当年边际税率本就是3%，缴时省约360元、领取时缴约360元，静态差额接近零，而资金需锁定至符合领取条件。

大额医疗支出有三层：基本医保、大病保险、医疗救助

保障与政策 · 政策原文

先看结论：基本医保有起付线与封顶线，超出自付部分进入大病保险；困难群体还有医疗救助。只按报销比例估算是错的。

住院费用的实际负担由三层结构决定，而不是一个报销比例。以公开的地方口径为例：基本医保设起付标准、分级报销比例与统筹基金年度最高支付限额；超过限额或自付累计超过一定额度后，进入大额医疗费用补助或大病保险，按更高比例报销并设年度限额；符合困难群体条件的还可申请医疗救助。普通门诊则走门诊共济，另有起付线、年度支付限额与分级比例。把三层结构写成一张表，才知道自己真正要准备多少现金，而不是看到“报销80%”就以为风险已覆盖。

现在能做的三件事

  1. 向参保地索取或查阅当年的起付线、分级报销比例、统筹基金年度最高支付限额，以及大额或大病保险的起付额、比例与限额。
  2. 用一次中等住院和一次重大住院两个情景分别试算自付金额，看现金缺口有多大。
  3. 确认家人是否符合困难群体或医疗救助条件，以及慢特病门诊的认定与报销路径。

具体情景 / 算例：虚构：某统筹区公开口径为大病保险起付标准8,000元、报销60%、年度限额35万元。若一个结算年度内符合规定的个人自付费用累计28,000元，则超过起付线的20,000元按60%报销，约12,000元，实际自付约16,000元，而不是按某个住院报销比例直接折算。

适用边界：起付线、比例、限额、目录与救助资格均由统筹区规定并逐年调整；上例仅示范结构，不能用于估算个人费用。

我想休息三个月，要准备多少钱？

你可能没有打算退休，只是希望有一段不用回复工作消息的时间。最难的常常不是批准自己休息，而是不知道：第三个月结束后，如果还没恢复、也没有找到新工作，怎么办？

把这次选择写成一段有预算、有检查点、可以延长或结束的休息。休息三个月和三个月后一定重新拿到工资，是两个假设。先给前者安排生活，再给后者留下余地。

先把三个日期分开

在纸上写下最后一笔正常工资到账日、计划重新找工作的日期、保守估计下一笔工资到账日。最后一个日期要考虑面试、入职和发薪间隔；不要直接用“休息结束”代替。

如果你想完整休息三个月，可以另留一段找工作和等待收入的窗口。窗口多长，用自己的行业、岗位和近期求职反馈判断。还没有线索，就先各算“再等一个月”和“再等三个月”，看差异能否接受。

90,000 − 15,000 − 3,000 = 72,000 元。

给休息安排内容，也给它留白

不用把三个月排成自我提升训练营。可以每周固定一两次见人、适量的日常活动，以及一段完全没有产出要求的时间。先用 一周生活设计 写一个普通星期，看看你期待的生活究竟是什么样。

如果准备长途旅行、进修或搬家，把费用单列为一次性项目。不要一面按低成本日常生活计算，一面默认休息期间可以随时增加旅行。也别把“以后接点活”算入已有资金，除非有明确的工作、成本和到账安排。

提前约好什么时候调整

比“没钱再去上班”更可执行的，是写下一张小卡片：

  • 每月底核对一次余额和下一阶段已知支出，平时不用天天盯表。
  • 到第八周，检查自己是想继续休息、尝试不同工作，还是开始求职。
  • 如果未来三个月预计现金支出超过可安排资金，提前缩短休息、调整非必要项目或启动收入计划。
  • 如果家人临时需要一笔钱，先重算窗口，再决定是否动用原来留出的专款。

触发条件由你决定。它的用途是让行动发生在仍有选择的时候，不是给休息设置绩效。

最容易漏掉的四件事

最后工资、报销和奖金应按实际到账时间处理；信用卡还款要和原消费对账，避免重复；原单位提供的某些支出支持可能不再存在；重新工作可能增加通勤、置装或过渡住宿费用。社保医保衔接单独查 政策导航，不要从别人的离职经验推定自己的情况。

只有 5 万、10 万、30 万，离选择权有多远？

看到别人用几百万元本金讨论退休，很容易觉得自己没有资格开始。但积蓄还不多时，值得解决的问题已经很多：可以拒绝一次不合理加班吗，能否承受换工作时收入短暂下降，家里有急事时是否只能借钱？

金额相同，能做的选择也可能完全不同。一个有房贷、需要支持家人的人，与一个住房稳定、负担较少的人，不能直接比较存款数字。本页用同一组假设解释方法，请把假设换成自己的账单。

先给钱命名，再计算能用多久

这里的“现金总额”指低波动且可及时支取的资金，不包含自住房、尚未归属的权益或难以变现的物品。把钱分成三栏：已经有用途的预留、为这次选择支付的一次性费用、剩余可安排资金。

预留不是一个人人相同的比例。它可以对应已知学费、房屋维修、家庭约定的支出。一笔钱被排除在可安排资金之外后，就不能再把它所覆盖的同一笔费用重复计入本次生活预算。对尚不确定的大额事件，可以另外设情景，不必假装每种风险都已经发生。

钱不多时，选择可以更小一些

如果接近第一种起点，可以先检查工资晚到、一次搬家或短暂求职能否承受。一次两周的休息、边工作边面试、与现雇主讨论工作安排，都可以成为值得比较的选项。它们是否可行需要真实条件，不自动适合每个人。

如果接近第二种起点，可以把“完整休息”与“换岗期间降收入”放在同一张账上。例如每月支出 6,500 元，新工作税后到账 5,000 元，每月缺口是 1,500 元；六个月缺口 9,000 元。仍要另外检查新工作是否稳定、何时到账和一次性费用，不能只看到缺口小就忽略劳动条件。

如果接近第三种起点，重点可能转向钱的不同用途：哪些用于较长的职业尝试，哪些仍要留给生活责任，未来是否需要恢复全职。先做一个三至十二个月的实验，记录真实支出和体验，再把观察带回长期模型。

不要只盯着“攒到下一个整数”

从 5 万到 10 万不一定需要把所有快乐删掉。先从账单里找反复发生、价值却很低的项目，再检查收入是否有可验证的改善空间。节省 500 元与接受一份每月多 2,000 元但明显增加消耗的工作，是两种不同的交换。

也别为了凑本金把备用钱放进自己不了解的高波动安排。这里计算的是需要时能拿到的钱，账面估值上涨不能替代下一次房租。

这周只做三件事：给每笔存款写一个用途；计算三个月无收入与六个月少收入的版本；选一个成本较低、能在一个月内结束或调整的小实验。积蓄的第一种用途，可以是让下一步不必那么仓促。

降薪换轻松一点的工作，究竟换到了什么？

你可能愿意每月少赚几千元，换一个不用下班后随时待命的生活。但“轻松”写不进银行流水，也常常只出现在招聘描述里。真正要比较的是：少了多少可用收入，多了哪些能由自己安排的时间，这个变化能持续多久。

先把想减少的东西写具体：夜间响应、长通勤、周末占用、管理冲突，还是工作内容本身。换工作能否解决问题，需要岗位证据；降薪本身不会自动买到轻松。

先算能否维持，再算值不值得

下面是虚构人物小周的两份工作。收入均为税后实际可用金额，预算暂按相同的 9,500 元比较，不假定新工作更省钱，也不计奖金和投资收益。

把时间也放进比较表

小周暂估现工作每周工作 50 小时、通勤 10 小时、额外待命 5 小时，共占用 65 小时；新工作分别是 40、5、0 小时，共 45 小时。按一年 48 个工作周简化，全年减少占用：

（65 − 45）× 48 = 960 小时。

用减少的年储蓄 60,000 元除以 960 小时，约为每小时 62.5 元。这是小周在这组假设下，为减少工作占用付出的储蓄代价，不是劳动时薪，也不是对自由时间的统一价格。待命和通勤的感受并不相同，所以原始分项要保留。

接下来问：多出来的时间在什么时段？每天晚上提前一小时，与每季度集中多几天假，能做的事不同。写出你会因此真正增加的一件事：一起吃饭、照顾家人、学习、运动或安静休息。若只能写“应该会更开心”，就先做更小的体验验证。

想确认的事可以问什么有用的证据

另外算一个不顺利的版本

新工作如果连续三个月实际到账只有 10,000 元、每月支出增加到 10,500 元，每月缺口就是 500 元，三个月合计 1,500 元。它可能在现金上承受得起，却未必值得接受：职责增加、成长停滞、时间仍被占用，都需要单独判断。金额小不代表决定轻。

别遗漏年终奖的实际归属和发放、通勤变化、必要设备、跨城住宿，以及因为多了空闲而增加的消费。所有新旧方案都用同一口径，年支出不要漏，已计入税后收入的扣款不要重复扣。

半退休的兼职收入突然停了，生活还能继续吗？

“每月赚一点，剩下的从积蓄里拿”听起来比完全退休容易。难点在于：项目可能推迟，客户可能停止合作，你也可能发现自己不愿意继续做。半退休计划应该允许兼职变化，不能只有每个月准时进账的版本。

把兼职看成一段需要劳动、存在成本、有开始和结束时间的收入。它能减少某段时间的支取，不能因为当前赚到一次，就变成永久资产。

算到账净额，不算报价和忙碌程度

以下是虚构人物阿宁的一年实验，金额为人民币元。阿宁现金 180,000 元，另留 30,000 元用于一项已知家庭支出，购买设备及启动工作花 6,000 元，实验可安排资金为 144,000 元。家庭专款负责的支出不再计入这张实验账。

每月生活与必要缴费共 8,000 元。兼职计划每月客户付款 5,000 元，扣去实际经营成本和为相关税费预留的合计 1,000 元，暂按净到账 4,000 元处理。1,000 元只是本案例假设，不是税率或对任何业务的税费判断。

把“持续工作”拆成可验证的几件事

先记录四周实际工时：获客、沟通、交付、修改、学习、催款都算。阿宁假设每月净到账 4,000 元，实际投入 50 小时，净收入约 80 元/小时；如果额外发现每月还有 20 小时获客，总投入 70 小时，就约为 57.14 元/小时。两个结果的区别来自漏记劳动，不来自交付报价。

再看收入是否集中。如果多数收入来自同一客户，对方停单时不会有多个来源同时托底。客户数量、合作时长、回款习惯、可替代业务，比社交平台上展示的单月收入更能帮助判断。还没有真实客户时，可以先做小额试单，不把设想放进基准账。

最后检查时间是否符合半退休目的。为了少上班而接下需要全天候回复的兼职，可能只换了付款方式。写清每周最多投入多久、哪些时段不接工作、哪类任务即使赚钱也不接。

观察到的变化先做的动作下一次检查
回款延后，但已有明确进度按实际到账更新现金表，暂缓新增经营支出两周后
连续两个月没有可确认的新单用零收入版本重算，检查必要与可调支出当月底
未来六个月预计支出将超过可安排资金启动已准备的求职或其他收入方案每周检查行动进展

这是案例中的管理方法，不是普适的两个月或六个月标准。你可以更早行动，也可以有更长窗口；关键是不要等资金只够下个月才第一次讨论替代方案。

设备折旧、平台费用、退款和坏账可能使净额低于预期。还要考虑客户是否愿意在你休息时等待、业务是否依赖某个平台、没有项目时会不会持续焦虑。保障安排单独核实 政策导航，不把“做兼职”当作已经解决了所有衔接问题。

这个月：完成一张净到账账、一张全部工时账；至少做一次实际小额交付；为一年收入正常、半年中断、全年归零各算一遍；把启动替代收入的条件写给未来的自己。兼职带来选择权的前提，是收入变化时仍有下一步。

搬去生活成本低的城市，真的会省钱吗？

你看到一个更便宜的城市，房租只有现在的一半，生活似乎立刻宽松了。但搬家会带来一次性支出，便宜的住所也可能离医院、亲友或工作机会更远。最值得计算的不是两张租房截图，而是搬过去之后一个普通年份的完整生活。

先确认生活方式能成立，再把节省写进计划。短住可以帮你发现问题，但短住的旅游节奏也不能直接代表长期居住。

单看月表，每年少花 18,000 元。小陈还预计每年多出探亲交通 6,000 元，因此经常性净节省为 18,000 − 6,000 = 12,000 元/年。原本就会发生的探亲已经在两地共同预算里，这 6,000 元只指迁居新增部分。

一次性不可退费用为 24,000 元：搬运 6,000 元、两地租期重叠 8,000 元、添置必需品 4,000 元、前期试住和考察 6,000 元。按费用全部发生在起点、以后均匀节省的简化算法，回收期是 24,000 ÷ 12,000 = 2 年。

对最容易变化的数字做压力检查

假设实际每月只比原城市少花 500 元，一年节省 6,000 元，恰好被新增探亲 6,000 元抵消，经常性净节省就是零，一次性费用无法靠节省收回。如果迁居还让税后月收入减少 2,000 元，一年少收入 24,000 元，即使保留原先 12,000 元净节省，全年现金流仍比原来少 12,000 元，另有搬家费。

收入变化和支出变化都要算。远程工作、当地兼职、房屋出租的收入，也应先核实稳定性和净到账，不因为搬到了便宜地方就默认它们持续存在。

再回答三件事：没有游客活动的一周会怎么过？需要照顾家人时，谁能来、自己怎么回去？如果这座城市不合适，何时、花多少钱能离开？便宜值得考虑，但朋友、照护和职业机会也需要正式占一栏。

01 为什么准备退休

准备退休，是逐步减少“必须接受某份工作才能维持生活”的程度。它可以改善今天的选择，不必等到某个年龄才生效。

“等退休”里藏着什么期待

“等退休了就去旅行、学游泳、陪家人”通常同时包含四个期待：钱够、时间自由、身体允许、重要的人还在。攒钱主要改善第一个条件，其他三个并不会自动随着存款一起增长。因此，把所有想做的事集中到一个遥远节点，实际上是在押注多个条件会同时成立。

这并不证明退休制度是骗局，也不证明人人应该马上辞职。更值得检查的是：你是否把一种不确定的未来，当成了当下长期透支自己的唯一补偿。

区分三个问题

问题可以怎样判断不能用什么代替
公共养老金未来能提供多少保障？查缴费记录、制度规则，做不同待遇情景一句“肯定没了”或“肯定够用”
我现在的工作值不值得继续？比较收入、消耗、成长、可替代机会只看别人几岁退休
我有没有在过自己想要的生活？看真实一周的时间分配只看净资产数字

养老金制度的风险、某份工作的代价、个人生活的失衡，应分开讨论。情绪可以提醒你有问题，但不足以直接给出金融结论。

给“够了”一个有边界的定义

尝试写三层生活：底线生活、愿意长期过的生活、可选升级。底线包括居住、食物、必要保障和照护；长期生活应包含你真正珍惜的兴趣与联系；可选升级可以随收入变化。

如果每次资产增长，目标就从小房换大房、从休息变成更高收入，再把“够了”整体后移，退休可能永远只是移动的终点。解决办法不是禁止升级，而是明确：这次升级会交换多少年的劳动？我愿意吗？伴侣也愿意吗？

一个当下实验

写下五件“等退休再做”的事，为每件补上三个字段：现在的最小版本、每月花费、每周时间。长途旅行可以先是一次三天短途；学一种技能可以先上四节课；陪家人可以先固定一个晚上。

不要把它们全部变成打卡任务。挑一件开始，四周后只问：我想继续吗？

02 选择你的路径

“继续熬”和“永远不工作”之间，还有很多可逆选项。

路径主要资金要求容易漏掉的代价适合先验证什么
按政策年龄退休补足养老金与支出的差额工作持续性、健康与照护变化如果提前失业两年怎么办
半退休 / 降低工时部分劳动收入加资产支取收入不稳定、福利变化降工时是否真的降低压力
阶段休息休息支出、保障、回归求职缓冲重返职场可能更慢、工资可能更低三个月休息后的状态

换工作、降责任、迁居转换成本只是换了另一种压力真正的痛点能否被解决

这里的“半退休”是生活描述，不是法定社保身份。“提前退出劳动”也不意味着可以提前领取基本养老金。

用三个约束筛选

首先看资金：必要开销能支持多久，保障是否接续，是否有尚未兑现的责任。其次看机会：目前有多少收入来自特定职位、城市或人脉，一旦退出能否恢复。最后看家庭：谁承担孩子接送、老人照护，谁在承受收入风险。

不要只为主情景投票。例如你希望半退休每年赚6万元，就再做一版两年赚不到钱的情景。如果只有理想收入实现时才能生存，这仍是依赖劳动的计划。

尽量先做可逆决策

可以先请假、试用较低预算、与单位讨论岗位或工时、验证兼职需求，再考虑长期退出。但请假和工时调整需要实际协商，不能假定单位支持。试运行也不能违反现有合同义务。

三个月试运行可以观察睡眠、支出、关系和动力；它不能证明未来四十年的经济可持续性。财务压力测试与生活体验必须同时做。

03 先做一份真实账本

你需要的不是一个好看的净资产总数，而是能解释钱从哪里来、什么时候必须花的账本。

第一步：看十二个月，而不是一个省钱月

汇总银行、支付工具和家庭共同支出。避免把信用卡还款与原消费重复计算，也不要把账户之间的转账当支出。年度旅游、保险、维修、礼金和家电更换都应计入。仅用最近一个月乘十二，容易漏掉大额低频项目。

把支出分成：

  • 必要经常支出：住房、基本生活、通勤、保障缴费、固定照护。
  • 可调经常支出：餐饮升级、娱乐、部分旅行与非必要购物。
  • 阶段责任：学龄期间教育、未还完的贷款、若干年的家庭支持。
  • 一次性大额：换房、装修、购车、手术自付或搬家。

分类是为了知道什么能调整，不是给消费判高低。一个持续带来快乐的爱好，可以在你的长期预算里拥有正式位置。

第二步：区分资产的用途

项目进入可支取资产？处理方式
可随时支取的存款、可交易投资按可变现金额留意税费、波动及赎回限制
自住房默认不进入只有计划变现或出租时，才计净现金流；同时补上替代居住成本
未归属或难变现的期权不按账面估值计入兑现后再进入资产；另列乐观情景
个人养老金等受限账户不进入早期流动资产到符合领取条件时按税后可用额或收入计入一次
子女教育或照护专款二选一从资产剔除并单独覆盖对应开销，或保留资产并计入对应支出
贷款不重复扣除要么立即偿还并扣资产，要么保留本金并列未来还款现金流

同一笔钱不能同时作为应急金、首付和退休本金。专款若从资产扣掉，却仍把它负责覆盖的开销全部留在退休账上，也会重复保守；必须写清用途对应关系。

第三步：把收入写成税后、分阶段

工资、兼职、租金、养老金分开列。租金扣除空置、维护、税费和管理成本。工资按税后可用金额，避免又扣一次已经代扣的社保。停止全职后新增的个人缴费，应单独纳入支出。

给每个收入写“起始年龄、结束年龄、是否随物价变化、可靠性”。养老金还没开始领取，就不能从现在的开销里直接减掉。

两个简化指标

可用现金缓冲月数 = 低波动且可及时支取的缓冲资金 ÷ 每月必要现金支出。它描述短期承压能力，不是退休年限。

年度储蓄 = 当年税后收入 − 当年实际支出。不同家庭对购房本金和投资交易的记法可能不同；比较前先统一口径。不要用浮动投资收益掩盖持续的生活赤字。

04 退休现金流怎么计算

先把时间拆开

35岁离开全职、63岁开始领养老金，就有28年的桥接期。桥接期可能还要缴纳保障费用、抚养孩子；领养老金后则可能增加照护支出。把一生写成“年支出减养老金”，会提前借用尚未到来的收入。

本仓库的计算以年度为单位：先结算当年收入与支出，再对剩余资产计算当年收益。它适合比较情景，不适合安排每月付款或判断某一天的流动性。

统一购买力

名义收益是账户数字的变化，实际收益是扣除通胀后的购买力变化：

实际收益率 = (1 + 税费后名义收益率) / (1 + 通胀率) - 1

假设税费后名义收益4%、通胀2%，实际收益约1.96%，不是精确的2%。这是算术例子，不是收益预测。

工具采用实际口径：输入今天价值的支出，之后保持其购买力不变；输入实际收益率。不要再把同一支出逐年加一次通胀，否则重复计算。养老金输入也必须是起始时点的购买力；如果未来固定名义金额不变，其实际价值会下降，需要用分阶段收入近似，或另建更精细模型。

提取率只能用于第一轮筛选

如果每年需要资产支持12万元，按不同初始提取率反推：

假设提取率12万元对应本金
2.5%480万元
3%400万元
4%300万元

这些是除法结果，不是安全阈值。经典“4%规则”通常指第一年取初始资产4%，之后按通胀调整取款金额；不是每年永远取剩余资产4%。后者会随市场变化大幅改变生活费。

Morningstar 的相关研究讨论了市场、期限和支取方式的关系；其2026介绍页给出的数字为3.9%，也强调策略差异。来源 S6 本仓库不把这一美国市场研究数字迁移为中国家庭的保证值。货币、税费、可投资资产、退休年限和养老金覆盖都不同。

相同长期收益，也可能有不同结果

虚构例子：本金100，每年年初取10。收益先-20%后+25%，两年后77.5；顺序反过来，结果82。两条收益路径的连乘都等于1，但早期亏损时卖出资产，会改变后续能参与上涨的本金。

因此固定2%实际收益只是可解释的基准线，不能表达市场风险。工具额外提供前两年-20%、-10%的压力路径，作为故意构造的坏情景，并非历史回测或概率预测。

至少比较五个变化

  1. 长期实际收益下调，甚至为零。
  2. 开始支取时连续下跌。
  3. 兼职收入消失、养老金低于预计或开始更晚。
  4. 一次大额支出加持续照护开销。
  5. 活得比原计划更久，或伴侣需要更长支持。

每次先改变一个变量，看计划最敏感于什么，再组合坏消息。期限末资产为正只说明该情景的算术成立；没有纳入模型的风险不会因为结果是绿色就消失。

05 中国大陆政策导航

政策核查日期：2026-10-12。以下为检索到的国家层面文件要点，不是对个人资格的核定。对象主要为职工养老保险参保者；城乡居民养老保险、特殊工种等不能直接套用。本章不自动推算个人退休日期。

三件事分开查

停止工作是劳动与生活安排；达到法定退休条件是制度判断；能领多少养老金是待遇计算。自己存够钱，不会自动改变后两者。

2024年全国人大常委会决定自2025年起实施渐进式延迟退休，用十五年逐步把男职工原60岁调整至63岁，原50岁和55岁退休的女职工分别调整至55岁和58岁。具体月份、身份与特殊情况需要查适用规则，不能对所有人直接说“现在都是63岁”。S1

职工按月领取基本养老金的最低缴费年限从2030年起，由15年逐年增加6个月，至2039年达到20年。最低年限是资格门槛，不等于缴满以后待遇不再变化。S2

满足相应条件可以选择弹性提前退休，距法定年龄最多提前3年，且不能低于原有50岁、55岁或60岁年龄底线。提前选择要符合所选年份的最低缴费年限；弹性延迟则适用法定退休年龄对应年份的最低缴费年限。延迟退休需要与单位协商一致，不能简单理解为自己单方想延就延。S3

养老与医保是两本账

国家医保局说明，退休后享受职工医保待遇涉及最低缴费年限；办理需符合当地规定。S4 不要拿养老的15年或20年直接当作医保年限。

离职前，向参保地经办机构核实：可选择的参保身份、缴费基数和金额、待遇衔接日期、中断后的等待或恢复规则、异地就医手续。需要跨城市退休的，还要确认养老待遇领取地和医保关系处理。把答复日期和办事页面留档。

个人养老金：优惠与限制一起看

现有公告规定个人养老金缴费在每年12000元限额内，可按规则在综合所得或经营所得中据实扣除；账户投资收益暂不征个税，领取时按3%单独计税。S5

抵扣不是退回12000元。实际税收效果取决于适用所得、税率与缴费前后的税额变化。还应比较产品费用、风险、可用性和资金锁定成本，不能只凭“省税”作决定。

2025年9月起实施的领取通知，除达到领取基本养老金年龄、完全丧失劳动能力、出国境定居等情形外，还规定了符合具体条件的医疗支出、失业保险金领取和低保情形。S7 这不等于普通辞职即可自由取出；不在此压缩复述复杂门槛，办理时查通知全文。

你需要拿到的六个答案

  • 我属于哪一类参保和退休身份？适用哪个出生年月对照？
  • 我的养老累计年限与医保累计、实际年限分别是多少？
  • 如果停止全职工作，接下来如何参保，费用是多少？
  • 哪个地方负责待遇领取与医保退休确认？
  • 当前养老金估算基于什么工资、年限和未来假设？
  • 哪些账户现在不能用，将来何时、税后多少可用？

工具中的养老金年龄和金额由用户手工输入，不会审查政策资格。不确定时，先用“暂不计入养老金”的保守情景；也保留合理估计情景，避免把不确定性误写成确定的零。

06 让计划承受坏消息

一个计划的质量，更多体现在出了问题以后还能怎样调整，而不是基准收益下的终值有多大。

用风险表代替一个“保守系数”

风险早期信号可以事先准备的动作
工资或兼职中断客户集中、合同即将结束、行业岗位减少单列无收入期；延后不可逆大额支出
市场连续下跌资产低于计划轨迹重新测算，使用已准备的流动资金，调整可选支出
家庭支出上升子女阶段变化、家人需要长期照护为持续支出建阶段，不只加一次“应急金”
资金暂时取不出锁定期、赎回限制、出售周期按到期日排列资产，匹配未来付款
人生目标改变生育、迁居、分居、换房重开家庭会议，重新划分共同责任

流动性缓冲规模没有对所有人都正确的月数。可以把6、12、24个月必要开销作为比较情景，看分别占用多少资金，以及相应的机会成本。这里是实验参数，不是推荐标准。

投资只服务于支出安排

先列未来几年必须支付的金额与日期，再讨论能承担多少波动。不能因为“长期收益更高”，就把下季度要付的费用全部放进可能大跌的资产。

分散投资可以减少单一资产或发行人的集中风险，但不能消除整体市场、通胀与汇率风险。境外收益率也不能忽略换汇、税费和实际可投资渠道。没有任何固定收益假设可以替代具体产品的风险与条款检查。

保障的核查顺序

先确认基本医保等保障的连续性，再查看已有商业保单负责什么、不负责什么。逐项看保额、免赔额、续保条款、等待期、除外责任和未来保费。寿险需求应围绕仍依赖你收入的人与未清偿责任讨论，不因“准备退休”自动增加或取消。

医疗费与照护费分开：有人长期失去独立生活能力时，需要的可能是持续陪护、无障碍改造和家人减少工作，并不全是可报销医疗支出。金额需按所在城市和家庭安排估价，本指南不提供全国统一价格。

预先写好调整规则

可以写：“如果未来两年的必要支出缺乏流动资金覆盖，先暂停可选大额购买并更新模型，再决定是否增加工作。”规则应对应具体风险和可执行动作，而非市场跌一点就恐慌卖出。

至少列出一个不依赖投资反弹的备选：降低可选消费、延后退出全职、增加已验证收入、调整住房方案。不能把“市场迟早涨回来”写成唯一应急办法。

07 家庭、住房与照护

退休计划通常会改变其他人的生活。账面上由一个人作决定，实际成本却可能由伴侣、父母或孩子承担。

自住房带来什么，不能带来什么

自住房可以降低租住的不确定性，但仍有物业、维护、维修和迁居成本。总价300万元的房子，不能同时算作300万元退休投资本金。如果未来卖大换小，只能计扣除交易成本、剩余贷款和新居费用后的释放资金。

比较买房与租房时，至少把首付或全款占用、贷款现金流、交易费用、维护、租金和未来变动放到同一时间轴。不要只比较月供和月租，也不要假设房价必涨。住所附近的医疗、交通与支持网络，可能比某个更便宜的城市更适合老年阶段。

家庭责任有阶段

子女教育不一定平均分布在四十年里；父母需要照护也可能早于自己退休。把责任写成时间段，每段说明谁出钱、谁出时间。老人愿意帮忙带孩子，不等于有无限且不变的照护能力。

对于尚未决定的生育或住房升级，可以保留A、B两套预算；不必为了得到一个精确退休年份，假装人生决策已经完成。

伴侣之间需要讨论的不只是钱

共同资金和个人资金如何划分？谁承担家务、谁保留职业？一人先退出工作是否会让另一人觉得被迫继续？如果兼职需要晚间和周末，是否侵占两人原本想获得的共同时间？

讨论时把“我怕什么”与“我要求你做什么”分开。例如“我担心现金不够，希望先试六个月预算”比“你就是不敢退休”更有建设性。双方可以保留不同风险偏好，不要求一次谈出最终答案。

照护安排与信息可达

至少让可信任的家人知道重要文件存放位置、保单及经办联系方式、紧急联络人。不要在共享表或公开仓库写银行密码、验证码、身份证完整号码。涉及遗嘱、监护、继承或大额财产安排时，需要适用地区的专业意见，不使用本仓库模板替代法律文件。

08 工作与再就业

工作除了收入，还可能提供结构、关系、认可和学习机会。退出一份工作时，要知道自己想减少哪部分，又希望保留哪部分。

先辨认消耗来自哪里

连续几周记录：真正疲惫的是通勤、工时、随时在线、管理关系、任务本身，还是缺少自主权？如果主要痛点是夜间响应，换一个岗位可能比完全退出劳动更合适；如果任何有考核的安排都让你无法恢复，一段休息可能更有价值。

这不是诊断工具。持续影响日常功能的身心问题，应寻求合适支持，不能要求自己单靠财务规划解决。

为技能保留可迁移的证据

对知识工作者，记录你解决过什么问题、怎样验证结果、哪些经验可以跨公司复用。公开作品要遵守保密与知识产权义务，不把公司代码、数据和内部文档上传出来。

AI等技术变化可能改变岗位要求，但不要把“必然永久失业”或“任何时候都能找回原薪资”当作唯一预测。更有用的是每隔一段时间真实查看岗位、与同行交流、做一次能力验证。

兼职收入先小规模验证

“以后做咨询每月赚5000元”是一个假设。至少检查：谁会付钱、获客花多少时间、收入有没有季节性、扣成本和税后还剩多少。没有实际客户时，在基准模型里谨慎处理，并一定做零收入情景。

所谓被动收入也可能有劳动：出租需要维护，内容产品需要更新，小生意有客服和获客。记录实际工时，计算自己是否愿意长期这样生活。

离职前的一页清单

确认财务缓冲、保障衔接、合同义务、已归属权益、归还设备和个人资料交接。确定休息预算与重新求职的触发条件。保留职业联系，但不把休息期变成每天追踪行业变化的另一份全职工作。

求职能力是备选，不是保险合同。行业低谷时再就业可能耗时更久，因此不能用一句“没钱再去上班”填平所有模型缺口。

本章产出：写清“我希望减少的工作特征”和“我希望保留的工作价值”，分别不超过三条。

09 生活、健康与身份

退休让一些外部任务消失，却不会自动产生一份适合自己的生活。特别是长期以成绩证明自己的人，可能把升职考核换成运动成绩、资产排名、旅行数量，仍然没有获得休息。

有目标与必须证明自己不是一回事

想拿一块完赛奖牌、学会一种技能，都可以是乐趣的一部分。可以问自己：没有奖牌，我还愿意做其中哪些部分？这次没达标，我能否仍承认这段经历有价值？我有没有允许自己纯粹消遣？

不必强求每一项兴趣都“只享受过程”。目标可以帮助投入，但不应成为评价整个自我的唯一依据。这个判断属于本指南的生活建议，不是对任何人的心理诊断。

先安排一个普通星期

试着保留几类活动：照料身体、与人联系、投入一件有兴趣的事、处理家务，以及没有产出的空白时间。不要马上排满每天，也不要把旅游旺季的一周想象成几十年的日常。

例如星期二上午散步买菜，下午读书或做饭，晚上和朋友见面。这种普通日子是否令你安心，比“退休后环游世界”的口号更能帮助设计预算。

让关系有重复发生的机会

离开职场后，很多见面不会再自动发生。选择能够重复参与的活动：兴趣小组、社区活动、固定聚会、学习或志愿服务。目标是形成可靠联系，不是积累社交数量。

伴侣也需要独立时间。不要把对方变成退休生活唯一的陪伴来源，或默认孩子应该填满你的空闲。

身体条件进入计划，但不做恐吓

这里不提供运动处方或统一体检套餐。可以盘点现有医疗安排、日常活动的可持续性、住房是否便利，以及生病时谁能帮助。高强度旅行与安静爱好可以分阶段安排，但不必由“以后一定做不了”的想象催促每一次消费。

从一件低成本、可持续的小事开始，比先买齐一整套设备更能检验兴趣。如果失去工作结构后，持续出现明显低落、孤立或难以维持日常生活，考虑求助可信任的人和专业支持。

本章产出：填 一周生活草图，允许空白；一周后记录感受，不打总分。

决策前检查

没有以下信息时，先补信息，不急着用一个退休金额替代它们：

  • 必要生活预算是否来自真实记录？
  • 养老金开始之前的每一年是否有资金来源？
  • 医保等保障如何衔接，已向适用地区确认了吗？
  • 计划中的劳动收入是否已验证，消失后会怎样？
  • 家庭成员是否了解变化及自己的责任？
  • 糟糕情景出现后，调整动作能否真正执行？

这些检查不用于给人贴“适合退休”的标签。它们只标出还不知道什么。

多久复盘

建议选择一个自己记得住的固定年度时点。这是工作方法，不是监管要求。重大事件发生时提前复盘：失业、生育、迁居、关系变化、照护需求、资产大幅变化或政策调整。日常价格波动不需要每次都重做人生规划。

复盘按顺序问：生活目标变了吗；真实支出变了吗；资产与收入有什么变化；原假设是否失效；下一年只需要调整什么。不要每次都向上调目标，直到永远无法完成。

90天实验范例

把可选消费减少一个自己接受的额度，看看是否明显降低幸福感；固定保留半天不处理工作；与一个潜在客户验证兼职需求；核实一项社保疑问。四件事不必同时做。

结束时只需决定继续、修改或停止。停止一个不合适的退休方案，也是有用的结果。

12 常见误区

“退休是一场骗局，所以不用准备养老了？”

对远期承诺保持审慎，不等于未来不需要食物、居住和照护。你可以不把所有快乐延后，同时为未来的不确定性准备资源。两者可以同时成立。

“有年支出的25倍就一定能退？”

这是4%对应的数学倒数，省略了期限、资产组合、税费、通胀、波动和支出弹性。尤其年轻退出全职时，还可能面临很长的养老金桥接期。见现金流章。

“存款利息够生活，就完全没有风险？”

利率可能变化，物价和个人支出也可能变化。利息覆盖当年开销，只描述当前关系。长期模型要看实际购买力，并允许本金在计划中逐步使用或明确保留目标。

“房子也算资产，为什么不能算？”

可以算净资产，但不一定能支付账单。卖房或出租需要可执行方案，而且还要安排替代居住。净资产、可支取资产、现金流是三个口径。

“年轻人养老金直接按零算最安全？”

零可以作为压力情景，不能自动当作对制度的事实判断。只看零可能过度牺牲当下，只看乐观估算可能准备不足。保留多个情景，随着政策与个人记录更新。

“最低缴费年限满足后就可以不管了？”

最低年限解决部分资格问题，待遇和医保另有条件；在职参保义务也不能由一份退休规划自行取消。具体情况查适用政策，不能从本仓库推导停缴决定。

“半退休肯定比全职轻松？”

兼职可能带来获客、收入波动和缺乏边界，甚至更难休息。应验证实际工时、税后收入和自己愿意承受的压力。

“模型说能撑到95岁，就有很高成功率？”

没有。这里是确定性情景工具，没有概率分布或历史样本。95岁是测试终点，不是寿命预测；一条路径不代表真实未来。

“有目标才有动力，难道拿奖牌也不对？”

目标本身没有问题。观察的是：它是否增加你的投入与乐趣，还是让每次活动都变成自我审判。允许目标、过程和休息同时存在。

“为什么不直接推荐产品、城市和一个退休金额？”

这些选择对个人责任、生活偏好、税费和时点高度敏感。首版先提供可核查的框架与工具，避免让一个适合别人的答案变成你的隐含前提。

13 制度与数字速查

政策核查日期：2026-10-22。本章把散在条目里的制度要点收成一张表式的参考，不是对个人资格的核定。国家层面规则与地方统筹区口径分开标注：凡出现具体缴费年限、报销比例、基础养老金数额的地方数字，都只代表该地当年公开页面，不外推全国。办理前以参保地经办答复为准。

三支柱先分清

支柱是什么谁出钱什么时候能用
第一支柱职工或城乡居民基本养老保险单位与个人缴费、财政补助达到法定退休或领取条件，按月发放
第二支柱企业年金、职业年金单位与个人共同缴费按单位方案，通常随退休或离职规则处理

第一支柱的待遇不是“缴满就固定”：它由缴费年限、缴费基数、退休年龄和退休时当地计发基数共同决定，且国家建立正常调整机制。2025年企业和机关事业单位退休人员基本养老金全国总体调整比例为2%。S15

一、退休年龄：按出生年月查，不按标题记

自2025年1月1日起，用十五年时间渐进延迟：男职工和原法定退休年龄为55周岁的女职工，法定退休年龄每四个月延迟一个月，分别逐步延迟至63周岁和58周岁；原法定退休年龄为50周岁的女职工，每二个月延迟一个月，逐步延迟至55周岁。S8

官方解读给出的例子是：男职工1965年1月至4月出生的，法定退休年龄提高1个月，即60周岁零1个月；1965年5月至8月出生的提高2个月；1976年9月至12月出生的为63周岁。临近改革启动时点的人通常只延迟几个月，不会一下子晚退休好几年。S8

二、最低缴费年限：2030年起还要往上走

从2030年1月1日起，按月领取基本养老金的最低缴费年限由十五年逐步提高至二十年，每年提高六个月。按每年六个月推算：2030年为15年6个月，2031年为16年，此后逐年递增，至2039年达到20年。达到法定退休年龄但不满最低缴费年限的，可以按规定通过延长缴费或一次性缴费的办法达到最低缴费年限。S8

最低年限是资格门槛，不是推荐值。缴满门槛只解决“能不能按月领”，不解决“领多少”。

三、弹性退休：一个区间，两端都有硬条件

  • 提前：达到最低缴费年限可自愿选择弹性提前退休，提前时间最长不超过三年，且不得低于原法定退休年龄（女50、55周岁，男60周岁）；自愿提前的，至少在本人选择的退休时间前三个月以书面形式告知所在单位。S8S9
  • 延迟：达到法定退休年龄，与所在单位协商一致可以弹性延迟退休，延迟最长不超过三年；单位与职工应提前一个月以书面形式明确延迟退休时间等事项。实施中不得违背职工意愿，不得违法强制或变相强制。S8S9

弹性不代表随时可退。它改变的是你与单位之间的程序安排，不改变缴费年限这个硬门槛。

四、养老金怎么算：两笔账相加

国发〔2005〕38号确立的计发办法中，基本养老金由基础养老金和个人账户养老金组成（有视同缴费年限的另有过渡性养老金）：S10

基础养老金 = (当地上年度在岗职工月平均工资 + 本人指数化月平均缴费工资) ÷ 2 × 缴费年限 × 1%
个人账户养老金 = 个人账户储存额 ÷ 计发月数

计发月数随退休年龄变化，退休越晚、月数越小：S11S12

算例（虚构）：计发基数设为9,000元，本人平均缴费工资指数1.0，缴费年限30年，个人账户储存额200,000元。

  • 60岁退休：基础养老金 =（9,000＋9,000）÷2×30×1% = 2,700元；个人账户 = 200,000÷139 ≈ 1,438.8元；合计约 4,138.8元。
  • 63岁退休且缴费至33年：基础养老金 = 2,970元；个人账户 = 200,000÷117 ≈ 1,709.4元；合计约 4,679.4元。

若平均缴费工资指数为0.6（长期按较低基数缴费），指数化月平均缴费工资为5,400元，同样30年缴费的基础养老金为（9,000＋5,400）÷2×30×1% = 2,160元，比指数1.0少540元。这就是“多缴多得、长缴多得”在算式里的位置。

上例未计入过渡性养老金、地方增发项目、记账利率与计发基数年度调整，只示范口径。

五、医保：年限、异地和三层报销

年限是两把尺。 职工医保退休待遇通常要求累计缴费年限男满30年、女满25年，且在本统筹区实际缴费满若干年；有的统筹区还设过渡期。以某统筹区公开页面为例：男30年、女25年，且本地缴满10年；男职工退休年限设过渡期，2025年底前退休按25年执行，2026年26年、2027年27年，逐年递增到2030年及以后按30年执行。S18

年限不足时，一般可在办理退休手续时一次性趸缴所差年限，或继续按月缴费至规定年限，期间按在职人员享受待遇；不补缴的，可能不享受退休人员医保待遇。S18S20

异地先看身份。 异地就医分异地长期居住与临时外出两大类：办理长期居住备案并在备案地就医的，报销比例通常与参保地一致；临时外出就医的，合规费用需个人先负担一定比例后再按参保地政策结算，或直接在本地报销比例基础上降低若干个百分点，转诊与急诊抢救另有口径。S18S20

大额支出有三层。 基本医保设起付线、分级报销比例与年度最高支付限额；自付累计超过一定额度后进入大额医疗费用补助或大病保险；符合条件的困难群体还可申请医疗救助。普通门诊走门诊共济，另有起付线与年度支付限额。S19

六、个人养老金：先算自己适用哪一档税率

自2024年12月15日起在全国全面实施。税收处理分三段：缴费环节按12,000元/年限额在综合所得或经营所得中据实扣除；投资环节投资收益暂不征收个人所得税；领取环节不并入综合所得，单独按3%的税率计税。S13S14

算例（虚构）：年缴12,000元。若当年边际税率20%，缴款少缴税约2,400元，领取时按3%计税约360元，静态差额约2,040元；若当年边际税率本就是3%，缴时省约360元、领取时缴约360元，静态差额接近零，而资金需锁定至符合领取条件。

领取条件在细化：除达到领取基本养老金年龄外，患重大疾病、领取失业保险金达到一定条件、正在领取最低生活保障金等情形也可申请领取，具体门槛查通知全文。S7S15

七、城乡居民养老保险：父母那一代的第二套制度

待遇由三块构成：基础养老金、个人账户养老金（个人账户储存额÷139）、以及多数地方按缴费年限加发的年限养老金。缴费档次从每年几百元到数千元不等，政府按档次给予补贴，当年缴费才有补贴、补缴不享受补贴。S21S22

中央层面，自2025年7月1日起全国基础养老金最低标准每人每月提高20元，所需资金由中央财政全额负担，惠及城乡老年居民约1.8亿人；在此之上有十余个省份进一步提高了本地标准。S15S16S17

地方差距很大，同一时期公开页面可见的基础养老金有约161元、166.5元、174元、242.5元等不同水平。给父母做预算，必须查父母户籍地的数字。S21S22S23

待遇领取人员需按周期完成资格认证，超过周期未认证会暂停发放；具体周期与办理方式由地方规定。S22

14 把钱换成生活

这一章讨论的是钱以外的一半：什么时间做什么事、削减的顺序、住在哪里、以及离开岗位后身份怎么重建。除明确标注的条目外，本章内容为原创整理的方法与判断，不是任何一本畅销书或某个流行主张的复述。流行说法里成立的洞见我会说明它成立的条件，不成立的部分我会直接写出边界。

一、有些事只能在这十年做

支出的价值不是随年龄线性衰减，而是在某一段之后陡降：需要连续体力的事、需要与父母或子女同行的事、需要重新学习一项技能的窗口，都有期限。反过来，阅读、本地聚会、看展这类活动在很宽的年龄段里都成立。把它们放在同一张预算表上平均分配，等于把稀缺的窗口期贱卖给了随时能做的事。

做法是分段：把自己的下一段人生按十年左右切成几段，每段写三栏。

分段只能这段做这段做更便宜可以推迟
第一段
第二段
第三段

填完检查“只能这段做”这一栏是否为空。为空通常不是因为你没有想做的事，而是你把想做的事都排到了以后。

二、体验预算：按三个问题排序

面对一笔非必要的大额支出，问三个问题：

  1. 十年后还能复述细节吗？ 不能复述的支出，价值随使用年限摊薄。
  2. 推迟五年还成立吗？ 依赖体力、同行者健康或特定关系状态的支出，推迟往往就不再成立。
  3. 需要他人参与吗？ 需要约人、约场地的支出，准备周期长，也更容易被临时支出挤掉。

至少两项答“是”的，排进当年预算；三项都答“否”的，排到最后。这不是鼓励多花，而是提示：很多大额支出落在价值最低的那一类，仅仅因为它最容易下单。

三、削减的顺序：先减摩擦，别先减锚点

预算收紧时最容易砍掉的，是看起来可有可无的固定活动。但它们往往是维持身体状态、社交密度和时间结构的锚点，砍掉之后代价会以别的形式出现。

类型特征处理
摩擦型无记忆、可替代、重复决策产生先减，一个月后回看是否真无影响
锚点型每周固定、有社交或身体参与保留；必须减则换成更低成本的固定形式
可延迟型大额、能推迟而不影响生活排期，不取消

四、迁居：便宜的全成本

生活成本更低的城市，最直观的是房租差额，但它只是账上的一行。同时出现的变化还有：探亲往返的频率与费用、居住地就医的报销口径、原有社交网络失效后的重建周期、以及不适应时的回迁预留。

医保一项最容易被忽略。异地就医分长期居住备案与临时外出两类，待遇差别可能体现在先自付比例或报销比例降幅上，一次中等住院就能抵消数月房租差额。决定搬迁后，先完成异地长期居住备案，再安排就医；先用短期租住验证，不要一次锁死。

五、身份的三根支柱

工作同时提供三样东西：能换钱或被认可的能力、稳定的社会身份、把一周填满的外部约定。离职时它们一起消失，所以问题往往不是“没事做”，而是三样同时断了。

  • 技能：仍在增值的、可被兑换的能力。
  • 角色：每周出现一次、且“需要你”的位置。
  • 日程：固定时间的外部约定。

优先建日程：固定时间的活动比计划中的活动更容易坚持，也更快产生社交回报。只补一样通常不够——有技能没角色会变成零散接单，有角色没日程会很快松掉。

六、关系靠重复，不靠强度

关系依赖重复发生的场景。工作场所免费提供了每天见面的机会，离开后这个机制消失，衰减速度比预期快。有效的替代不是更盛大的聚会，而是成本更低、频率更高的固定安排：同一时间的运动、同一家店的早饭、同一门课。

迁居后优先选择能立即产生重复见面的活动，并把重建周期的预期设为半年以上。独处不等同于孤独，这里讨论的是希望维持关系密度时的做法。

七、“把钱在死前花完”的三个前提

把资产在生命终点精确归零，需要三个前提：没有需要长期支持的家人；医疗与照护支出可以按平均值规划；资产能按需要分批变现。在中国家庭的常见情形里，这三条往往同时不成立——父母养老金水平不高、长期照护成本集中在最后几年且分布很厚、主要资产常是不可分割的自住房。

风险不在“钱没花完”，而在最后一段需要现金时，钱被锁在不能快速处置的形式里。更可行的做法是分段：

  1. 体验预算：明确要在哪一段花掉、花在什么上。
  2. 家人保障：明确留给谁、以什么形式、触发条件是什么。
  3. 照护专项：单独存放，不与日常预算混用，明确动用条件。

算例（虚构）：总资产300万元，其中自住房占200万元。按“花完”思路编制预算时，可动用部分其实只有100万元；先划出30万元照护专项与20万元父母支持，剩余50万元才是可自由安排的体验预算——比原设想少一半以上。

八、每季度回看一次

时间、健康和家庭责任都会移动。每季度回看四件事：窗口栏里的事有没有被无限推迟；锚点支出有没有被误砍；角色是否还需要你、技能是否仍在增值；照护专项的触发条件是否仍然成立。

测算工具说明

Python 3.10+，只用标准库，不联网、不上传数据。原始私人配置建议放进 private/ 目录，该目录已加入 Git 忽略规则。

python tools/retirement.py examples/bridge.json --stress
python tools/retirement.py examples/bridge.json --csv projection.csv
python -m unittest discover -s tests -v

输入字段

字段含义规则
name情景名称可选字符串
start_age / end_age模拟起止年龄整数，起点包含、终点不包含；0至120
assets起点可自由支取的资产元，非负；排除自住房和不可取账户
annual_spending每年基础支出元，起始购买力；非负
real_return税费后实际收益率0.02表示2%，不能低于-1
incomes各段税后收入数组start_age、end_age、annual_amount，可加label
extra_expenses阶段额外支出数组同收入字段，叠加在基础支出上
events一次性支出数组age、amount，可加label；非负支出
return_overrides指定年龄年度收益例如 {"40": -0.2}，覆盖默认收益

数组默认空。各时间段必须完全落在模拟范围内；若缩短模拟期限，应同步截断收入和支出时间段，工具不会静默丢弃。相互重叠的收入和支出将相加。未知字段、非有限数值、负支出或无效年龄会报错退出，避免拼错字段得到假结果。

精确定义

年龄40这一行，表示40岁期初至41岁期初。end_age=95时，最后一行为94岁年度，结果为95岁期初资产。

年度先将全年税后收入加入资产并减去全年支出，再将非负余额乘以 1+实际收益率。这是“现金流先结算、收益后计算”的简化结算约定，并不总是比其他记账时点保守。年度内先支出后到账的流动性困难无法检测。

若收入加资产不足以支付当年支出，记录未覆盖金额，将可投资余额截为零。工具继续计算后续年度，但不会假设借款或自动偿还历史缺口。所以后期资产为正也不能消除早期失败。必须同时查看首次缺口与累计未覆盖金额。恰好花光但没有欠付不算缺口，仍意味着缓冲已耗尽。

CSV只导出基准路径，即使同时用了 --stress。字段：age=年龄年度；opening_assets=期初资产；income=收入；expenses=支出；net_draw=支出减收入，可为负；real_return=实际收益；unfunded=未覆盖支出；closing_assets=期末资产。累计缺口未折现，均为同一购买力口径。

压力路径

--stress 比较三条确定路径：原配置；全部年份零实际收益（清空覆盖）；前两年实际收益-20%与-10%（替换这两年的覆盖，其余年份保留原配置）。这些是说明性的假设，不是投资建议、历史回测或风险概率。

收入中断请删除或分割对应收入段；养老金推迟请修改其起点；一次性支出用events；持续照护用extra_expenses。组合情景另存配置文件，记录改动，便于复查。

模型没有做什么

没有逐月结算、税务计算、社保资格认定、名义通胀自动转换、资产类别再平衡、随机模拟、自动调整消费、贷款利息计算、夫妻分别的生存状态或遗产分配。输入的净收入与支出应已反映这些必要费用。不得把输出包装成精确退休年龄、成功率或收益承诺。

计算器只模拟一个综合资金池。受限账户不能直接放进早期assets；需要时可用一个年度收入段录入到期税后可用额，且避免在别处重复计入。固定名义养老金的实际购买力会下降，可拆成不同阶段近似；恒定实际收入假设意味着购买力保持。

机器可读输出与文件保护

python tools/retirement.py examples/bridge.json --stress --json 将所有所选情景和逐年明细输出到标准输出，JSON模式不会混入状态文本。schema_version 为1，金额单位写在 unit 中，minimum_closing_assets 是整个模拟期的最低年末资产。

可以同时指定 --csv；CSV仍只导出基准，导出提示写到标准错误。输出路径不得与输入相同，也不得覆盖已有文件。配置支持UTF-8及带BOM的UTF-8；重复JSON键会明确报错，避免一个资产金额静默覆盖另一个。
